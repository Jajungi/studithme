용액의 기본 · Solution Vocabulary

용액(solution)은 성분이 균일한 혼합물입니다. 시험 전반의 “분모·단위·평형” 오답은 대부분 여기서 시작합니다. **용매(solvent)**는 양이 가장 많고, **용질(solute)**는 그 안에 녹은 쪽입니다. Solvation / hydration은 용매가 용질을 둘러싸는 과정이고, 포화(saturated) 상태에서는 용해(dissolution)와 석출(crystallization)이 **동적 평형(dynamic equilibrium)**입니다.

시험에 나오는 형태

  • 정의형 (Practice Q1): saturated / supersaturated / solvation / exothermic dissolution 등 + 예시 1개
  • 개념형: “포화 용액에 더 넣으면?” “과포화는 안정한가?”
  • 연결형: dissociation → 이후 iii (전해질)

개념을 친절하게

  • Unsaturated: 더 녹일 수 있음.
  • Supersaturated: 평형보다 많이 녹음 — 메타안정, 씨앗·충격에 급격히 crystallization.
  • Miscible / immiscible: 액체–액체가 모든 비율로 섞임 vs 층 분리.
  • Enthalpy / entropy: ΔHsolution\Delta H_{\mathrm{solution}}ΔHsolution​이 exothermic / endothermic; ΔS\Delta SΔS와 함께 “왜 녹는가” 서술.

공식 · 기호

ΔGsolution=ΔHsolution−TΔSsolution\Delta G_{\mathrm{solution}} = \Delta H_{\mathrm{solution}} - T\Delta S_{\mathrm{solution}}ΔGsolution​=ΔHsolution​−TΔSsolution​

(개념·부호 수준; 정량은 단원마다 다른 식 사용)

생각 흐름 (시험장 루틴)

  1. 문제 읽기: “정의 + 예시”인지, “포화/과포화/평형” 서술인지 한 줄로 번역한다.
  2. 유형 판별: Q1 키워드면 2~3문장 정의 + 화학식 예; 선택형이면 동적 평형 / 불안정 키워드로 분류.
  3. 쓸 식 고르기 전 질문: “열역학 숫자 문제인가?” → 아니면 식 없이 용어 + IMF + 평형만 쓴다. “전해질인가?” → dissociation 언급 여부.
  4. 식 선택 + 이유: 숫자가 없으면 ΔG\Delta GΔG는 개념 보조만; 포화는 ratedissolve_{\mathrm{dissolve}}dissolve​ = ratecrystal_{\mathrm{crystal}}crystal​ 문장.
  5. 숫자 넣기 순서: 해당 없음 — 대신 예시 1개(KBr–물, 과포화 설탕)를 골라 IMF와 연결.
  6. 검산: “포화 = 고체 안 움직임”이면 오답; “과포화 = 안정 평형”이면 오답.
  7. 자주 하는 실수 한 줄: saturated를 “정적”으로 외워 동적 평형을 빼먹는다.
