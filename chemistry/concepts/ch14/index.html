반응속도론 개요 · Chemical Kinetics Overview

Reaction rate는 단위 시간당 농도 변화, mechanism은 reactants→products까지의 elementary step 순서입니다. Spontaneous(ΔG<0\Delta G<0ΔG<0) ≠ fast — kinetics와 thermodynamics는 변수가 완전히 다릅니다.

시험에 나오는 형태

  • O/X·선택: “자발적이면 빠르다”, “촉매가 KKK를 바꾼다”
  • 용어 정의 (Practice #1, ch14-08)

개념을 친절하게

강의 Introduction Q.: Do all reactions progress at the same speed? → 아니오. Does spontaneous mean fast? → 아니오. 반응식 읽을 때 state, condition, stoichiometry — N2(g)+3H2(g)→Fe2NH3(g)\mathrm{N_2(g)+3H_2(g)\xrightarrow{Fe}2NH_3(g)}N2​(g)+3H2​(g)Fe​2NH3​(g), CaCO3(s)→ΔCaO+CO2(g)\mathrm{CaCO_3(s)\xrightarrow{\Delta}CaO+CO_2(g)}CaCO3​(s)Δ​CaO+CO2​(g).

Ch.14 흐름: Factors → Rates → Rate laws → [ ][\ ][ ] vs time → Temperature → Mechanisms → Catalysis.

공식 · 기호

(개요) elementary에서 K=kf/krK=k_f/k_rK=kf​/kr​ 연결은 평형 이야기; 관측 rate는 kkk, order, EaE_aEa​ 층위.

생각 흐름 (시험장 루틴)

  1. 문제 읽기: “속도(얼마나 빨리)?” vs “평형(어디까지)?” vs “자발성(가능?)” 중 무엇인가?
  2. 유형 판별: thermodynamics 키워드(KKK, ΔG\Delta GΔG, ΔH\Delta HΔH) vs kinetics(kkk, order, t1/2t_{1/2}t1/2​, EaE_aEa​)
  3. 쓸 식 고르기 전 질문: 촉매/효소가 나왔는가? → KKK 불변 먼저 떠올리기
  4. 식 선택: kinetics 문제면 rate law / integrated / Arrhenius 중 하나
  5. 검산: “촉매 넣었는데 KKK 커졌다”는 답은 거의 항상 오답
  6. 자주 하는 실수: ΔG<0\Delta G<0ΔG<0이면 rate 크다고 가정

속도에 영향을 주는 요인 · Factors & Collision Model

네 가지: (1) physical state (2) concentration (3) temperature (4) catalyst. 분자 수준에서는 collision frequency + 충분한 energy(EaE_aEa​) + orientation.

시험에 나오는 형태

  • 4요인 나열·예 (steel wool vs nail, Fe/NH₃)
  • homogeneous vs heterogeneous; solid reactivity ↑ 방법
  • Cl + NOCl orientation 그림

개념을 친절하게

  • rate ×4 when [A] ×2 → 2nd in A

Uncatalyzed vs bromide-catalyzed H₂O₂ profile — peak lower, ΔH\Delta HΔH same.
