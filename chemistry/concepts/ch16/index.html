산·염기 정의 · Acid–Base Definitions

산·염기는 Arrhenius → Brønsted–Lowry → Lewis로 범위가 넓어집니다. 물에서의 H+\mathrm{H^+}H+/OH−\mathrm{OH^-}OH−, 양성자 이동, 전자쌍 이동을 구분해 쓰세요.

용어 · Arrhenius, Brønsted–Lowry, Lewis, amphiprotic, proton donor / acceptor, electron-pair acceptor / donor

Arrhenius

  • Acid: 수용액에서 [H+][\mathrm{H^+}][H+]([H3O+][\mathrm{H_3O^+}][H3​O+])↑ — 예: HCl\mathrm{HCl}HCl
  • Base: [OH−][\mathrm{OH^-}][OH−]↑ — 예: NaOH\mathrm{NaOH}NaOH
  • 한계: 수용액 한정; NH3\mathrm{NH_3}NH3​ 설명이 어색

Brønsted–Lowry

  • Acid: proton (H+\mathrm{H^+}H+) donor
  • Base: proton acceptor
HCl(g)+H2O(l)→Cl−(aq)+H3O+(aq)\mathrm{HCl(g)+H_2O(l)\rightarrow Cl^-(aq)+H_3O^+(aq)}HCl(g)+H2​O(l)→Cl−(aq)+H3​O+(aq)

물은 base.

NH3(aq)+H2O(l)⇌NH4+(aq)+OH−(aq)\mathrm{NH_3(aq)+H_2O(l)\rightleftharpoons NH_4^+(aq)+OH^-(aq)}NH3​(aq)+H2​O(l)⇌NH4+​(aq)+OH−(aq)

물은 acid → water is amphiprotic.

Lewis (개요 — 뒤에서 자세히)

  • Acid: electron-pair acceptor
  • Base: electron-pair donor
  • 양성자 없이도 가능: BF3+:NH3\mathrm{BF_3 +:NH_3}BF3​+:NH3​

미니 예제
HCl+H2O\mathrm{HCl + H_2O}HCl+H2​O: Arrhenius·Brønsted 모두 산.
NH3+H2O\mathrm{NH_3 + H_2O}NH3​+H2​O: Brønsted 염기(양성자 받음), Arrhenius로는 물과 반응해 OH−\mathrm{OH^-}OH−↑로 설명.
BF3\mathrm{BF_3}BF3​: Lewis 산이지만 Brønsted 산은 아님.

함정올바른 생각
모든 염기가 OH−\mathrm{OH^-}OH−를 가짐Brønsted는 proton acceptor면 됨 (NH3\mathrm{NH_3}NH3​)
Arrhenius = 모든 경우비수용액·Lewis는 범위 밖
amphiprotic = amphoteric 무시물은 상대에 따라 산 또는 염기

H+(aq)\mathrm{H^+}(aq)H+(aq)는 실제로는 수화되어 H3O+\mathrm{H_3O^+}H3​O+ 등으로 쓰입니다. 시험에서는 둘을 같은 pH 계산에 쓰는 경우가 많습니다. Lewis는 배위·유기 반응까지 확장됩니다.

짝산–짝염기 · Conjugate Acid–Base Pairs

양성자 하나 차이 나는 두 species가 conjugate pair입니다. 산이 강할수록 짝염기는 약합니다.

용어 · conjugate acid–base pair, stronger acid ↔ weaker conjugate base

HA(aq)+H2O(l)⇌A−(aq)+H3O+(aq)\mathrm{HA(aq)+H_2O(l)\rightleftharpoons A^-(aq)+H_3O^+(aq)}HA(aq)+H2​O(l)⇌A−(aq)+H3​O+(aq)
  • Forward: HA acid, H2O\mathrm{H_2O}H2​O base
  • Reverse: H3O+\mathrm{H_3O^+}H3​O+ acid, A−\mathrm{A^-}A− base
  • Pairs: HA/A−\mathrm{HA/A^-}HA/A−, H3O+/H2O\mathrm{H_3O^+/H_2O}H3​O+/H2​O

규칙:

  • Conjugate base = acid − H+\mathrm{H^+}H+
  • Conjugate acid = base + H+\mathrm{H^+}H+
  • Stronger acid ↔ weaker conjugate base (and vice versa)

미니 예제
HNO2/NO2−\mathrm{HNO_2 / NO_2^-}HNO2​/NO2−​, NH4+/NH3\mathrm{NH_4^+ / NH_3}NH4+​/NH3​, HSO4−/SO42−\mathrm{HSO_4^- / SO_4^{2-}}HSO4−​/SO42−​가 각각 conjugate pair입니다.
HCl(강산)의 짝염기 Cl−\mathrm{Cl^-}Cl−는 물에서 거의 염기로 행동하지 않습니다. CH3COOH\mathrm{CH_3COOH}CH3​COOH(약산)의 짝염기 CH3COO−\mathrm{CH_3COO^-}CH3​COO−는 상대적으로 더 센 염기입니다.

함정올바른 생각

강산의 짝염기도 강염기매우 약한 염기
H3O+\mathrm{H_3O^+}H3​O+의 짝염기 = OH−\mathrm{OH^-}OH−짝염기는 H2O\mathrm{H_2O}H2​O

세기 비교와 수평화 · Relative Strength & Leveling

물에서 강산은 사실상 완전 이온화하고, 실제로 다량 존재할 수 있는 최강 산 species는 H3O+\mathrm{H_3O^+}H3​O+입니다(leveling effect).

용어 · strong acid / base, weak acid / base, leveling effect

Common strong acids: HCl, HBr, HI, HNO3\mathrm{HNO_3}HNO3​, HClO4\mathrm{HClO_4}HClO4​, H2SO4\mathrm{H_2SO_4}H2​SO4​ (첫 번째 양성자).

  • 차트에서 물보다 위인 강산 → 수용액에서 H3O+\mathrm{H_3O^+}H3​O+로 leveling
  • 최강 염기 species(수용액)는 OH−\mathrm{OH^-}OH−

염 수용액의 액성 · Acid–Base Properties of Salts

염을 녹인 뒤 양이온·음이온을 각각 검사합니다. spectator는 중성, 약산/약염기의 conjugate는 가수분해합니다.

용어 · salt hydrolysis, spectator ion, amphiprotic anion

Cations

  • 강염기에서 온 금속 (Na⁺, K⁺, Ba²⁺, …): spectator → neutral
  • 약염기의 conjugate acid (NH₄⁺, …): acidic
  • 작고 전하 큰 금속 (Fe³⁺, Al³⁺, …): hydrated ion 가수분해 → acidic

Anions

  • 강산의 conjugate base (Cl⁻, Br⁻, I⁻, NO₃⁻, ClO₄⁻, …): spectator → neutral
  • 약산의 conjugate base (CH₃COO⁻, CN⁻, CO₃²⁻, …): basic
  • Amphiprotic (HCO₃⁻, H₂PO₄⁻, HC₂O₄⁻, …): 그 이온의 KaK_aKa​ vs Kb=Kw/KaK_b=K_w/K_aKb​=Kw​/Ka​(관련 짝) 비교

Combining

  • 산성 이온 + spectators → acidic
  • 염기성 이온 + spectators → basic
  • spectators만 → neutral
  • 산성 양이온 + 염기성 음이온 → KaK_aKa​ vs KbK_bKb​ 비교

Lewis는 전자쌍 이동으로 정의하므로 Brønsted보다 넓습니다. 양성자가 없어도 됩니다.

용어 · Lewis acid, Lewis base, adduct, coordinate covalent bond

  • Lewis acid: electron-pair acceptor
  • Lewis base: electron-pair donor
BF3+:NH3→F3B ⁣− ⁣NH3\mathrm{BF_3 + :NH_3 \rightarrow F_3B\!-\!NH_3}BF3​+:NH3​→F3​B−NH3​

참/거짓 점검:

  • Every Brønsted acid is a Lewis acid. True.
  • Every Lewis acid is a Brønsted acid. False (BF₃, metal cations, …).

미니 예제
AlCl3\mathrm{AlCl_3}AlCl3​, Fe3+\mathrm{Fe^{3+}}Fe3+, CO2\mathrm{CO_2}CO2​, BF3\mathrm{BF_3}BF3​는 전형적인 Lewis acids.
NH3\mathrm{NH_3}NH3​, H2O\mathrm{H_2O}H2​O, Cl−\mathrm{Cl^-}Cl−, ethers의 O:는 Lewis bases.
H+\mathrm{H^+}H+를 받는다는 점에서 모든 Brønsted 산은 (그 양성자가) Lewis 산 역할을 합니다.
