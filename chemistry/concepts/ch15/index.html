동적 평형 · Dynamic Equilibrium

개념

닫힌 계에서 반응이 오래 지나면 농도가 “안 변하는 것처럼” 보입니다. 그렇다고 분자가 멈춘 것은 아닙니다. 정반응 속도와 역반응 속도가 같아져, 거시적으로는 조성이 일정해진 상태가 동적 평형입니다.

N2O4⇌2NO2\mathrm{N_2O_4\rightleftharpoons 2NO_2}N2​O4​⇌2NO2​처럼 색깔이 바뀌는 기체가 교과서 단골입니다. 평형이어도 분자는 계속 N2O4↔NO2\mathrm{N_2O_4\leftrightarrow NO_2}N2​O4​↔NO2​를 오갑니다.

속도론의 kkk와 헷갈리지 마세요. 평형은 “얼마나 빨리”가 아니라 “어디로 치우쳐 멈추는 듯 보이는가”입니다. 촉매는 평형에 더 빨리 도달하게 하지만, 평형 조성(KKK)은 바꾸지 않습니다.

강의 자료: N₂O₄(무색) ⇌ 2NO₂(갈색). 색이 더 이상 안 변해도 정·역반응은 계속입니다.

공식

평형에서 vf=vrv_{\mathrm{f}}=v_{\mathrm{r}}vf​=vr​. 농도·압력으로 쓰는 식이 바로 KKK입니다 (다음 절).

  • forward / reverse reaction — 정반응 / 역반응

평형식 쓰기 · KcK_cKc​, KpK_pKp​, 균일·불균일

개념

평형 상수 KKK는 “생성물 쪽을 분자, 반응물 쪽을 분모”에 두고, 균형 반응식의 계수를 지수로 올립니다. 농도(또는 활도)로 쓰면 KcK_cKc​, 부분압으로 쓰면 KpK_pKp​입니다.

aA+bB⇌cC+dD⇒Kc=[C]c[D]d[A]a[B]baA+bB\rightleftharpoons cC+dD \quad\Rightarrow\quad K_c=\frac{[C]^c[D]^d}{[A]^a[B]^b}aA+bB⇌cC+dD⇒Kc​=[A]a[B]b[C]c[D]d​

순수 고체·순수 액체는 보통 식에서 뺍니다(활도 ≈ 1). 그래서 CaCO3(s)⇌CaO(s)+CO2(g)\mathrm{CaCO_3(s)\rightleftharpoons CaO(s)+CO_2(g)}CaCO3​(s)⇌CaO(s)+CO2​(g)의 KcK_cKc​는 사실상 [CO2][\mathrm{CO_2}][CO2​] (또는 Kp=PCO2K_p=P_{\mathrm{CO_2}}Kp​=PCO2​​)만 남습니다. 이런 경우를 불균일(heterogeneous) 평형이라고 합니다. 모두 같은 상이면 균일(homogeneous)입니다.

공식

기체만 있는 예: Kc=[NH3]2/([N2][H2]3)K_c=[\mathrm{NH_3}]^2/([\mathrm{N_2}][\mathrm{H_2}]^3)Kc​=[NH3​]2/([N2​][H2​]3). 고체가 끼면 고체 항 생략.

영어 용어

개념 용어

  • equilibrium expression — 평형식
  • homogeneous / heterogeneous equilibrium — 균일 / 불균일 평형
  • pure solid / pure liquid — 순수 고체 / 순수 액체 (KKK에서 생략)
  • activity — 활동도 (이상적으로 1로 둠)

KpK_pKp​와 KcK_cKc​ · Δng\Delta n_gΔng​

개념

같은 반응이라도 농도로 쓴 KcK_cKc​와 부분압으로 쓴 KpK_pKp​는 숫자와 단위가 다를 수 있습니다. 연결식은

Kp=Kc(RT)ΔngK_p = K_c(RT)^{\Delta n_g}Kp​=Kc​(RT)Δng​

여기서 Δng=\Delta n_g=Δng​= (기체 생성물 계수 합) − (기체 반응물 계수 합)입니다. Δng=0\Delta n_g=0Δng​=0이면 Kp=KcK_p=K_cKp​=Kc​입니다.

RRR과 TTT, 압력 단위를 KpK_pKp​ 정의와 맞추는 것이 실수 포인트입니다.

공식

Kp=Kc(RT)Δng,Δng=∑νgas,prod−∑νgas,reactK_p = K_c(RT)^{\Delta n_g},\quad \Delta n_g=\sum \nu_{\mathrm{gas,prod}}-\sum \nu_{\mathrm{gas,react}}Kp​=Kc​(RT)Δng​,Δng​=∑νgas,prod​−∑νgas,react​

KKK의 크기 · 무엇을 말해 주나

개념

KKK는 “평형에서 생성물/반응물 비”의 크기를 요약합니다.

  • K≫1K\gg 1K≫1 — 평형이 생성물 쪽으로 많이 치우침
  • K≪1K\ll 1K≪1 — 반응물 쪽이 우세 (거의 안 간 것처럼 보여도 평형일 수 있음)
  • K≈1K\approx 1K≈1 — 양쪽이 꽤 남아 있음

KKK가 크다고 속도가 빠른 것은 아닙니다. 큰 KKK와 작은 kkk가 동시에 가능합니다 (느린데 결국 생성물 쪽으로 가는 반응).

QQQ vs KKK · 이동 방향

개념

KKK는 평형일 때의 값입니다. 아직 평형이 아닐 때 같은 꼴로 숫자를 넣으면 반응 지수 QQQ가 됩니다.

  • Q<KQ\lt KQ<K — 생성물이 “부족” → 정반응으로 진행하며 QQQ가 KKK에 접근
  • Q>KQ\gt KQ>K — 생성물이 “과잉” → 역반응
  • Q=KQ=KQ=K — 이미 평형

외울 때는 “QQQ를 KKK에 갖다 붙인다”고 생각하면 됩니다. 농도를 갑자기 바꾸면 QQQ가 흔들리고, 계는 다시 Q=KQ=KQ=K가 되도록 이동합니다 (다음 절 Le Châtelier와 같은 이야기).

공식

QQQ는 KKK와 같은 대수식, 다른 점은 현재 농도를 넣는다는 것뿐입니다.

영어 용어

개념 용어

  • reaction quotient (QQQ) — 반응지수
  • compare QQQ and KKK — QQQ와 KKK 비교 → 방향
  • net reaction — 알짜 반응 (정 또는 역으로 진행)
  • disturbance / stress — 교란 / 응력

문제에서 자주 나오는 표현

  • predict the direction — 진행 방향을 예측하시오
  • shifts to the left / right — 왼쪽으로 / 오른쪽으로 이동
  • counteract the disturbance — 교란을 일부 상쇄한다

Le Châtelier · 특히 온도와 KKK

개념

평형을 방해하면 계는 그 방해를 부분적으로 상쇄하는 쪽으로 이동합니다. 다만 시험이 가장 좋아하는 구분은 이겁니다.

온도만 KKK 값을 바꾼다. 농도·압력·부피·비활성 기체는 보통 이동(QQQ)만 일으키고, 새 평형에서의 KKK는 같습니다.

  • 반응물 추가 → 정반응 쪽
  • 생성물 추가 → 역반응 쪽
  • 기체 반응에서 부피↓(압력↑) → 기체 mol 수가 적은 쪽
  • 흡열 정반응에 열을 가함(TTT↑) → 정반응 쪽, KKK 증가
  • 발열 정반응에 TTT↑ → 역반응 쪽, KKK 감소
  • 촉매 → 도달만 빠르게, KKK 불변

강의 자료: 평형 혼합물에 H₂를 더하면 정반응으로 이동해 일부를 소모한다 (KKK는 온도 고정 시 불변).

공식

정성 규칙 + (온도) van’t Hoff 직관: 흡열이면 TTT↑ → KKK↑.

  4. TTT branch:

  5. P/V branch ( TTT fixed ):

  9. 실수: conc change → KKK change; inert @ const V → big shift; exothermic + T↑ → more products.
