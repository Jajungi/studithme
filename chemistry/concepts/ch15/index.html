동적 평형 · Dynamic Equilibrium

화학 반응은 대부분 100% 끝까지 가지 않습니다. 생성물이 생기면 동시에 역반응도 일어나고, 어느 순간 정반응 rate = 역반응 rate가 되면 거시적으로 농도·분압이 더 이상 변하지 않습니다. 그런데 분자 수준에서는 계속 ⇌가 일어나므로 **dynamic equilibrium(동적 평형)**입니다. Ch.14와 헷갈리지 마세요: **rate(속도)**는 kinetics, **어디에 멈추는지(조성)**는 Ch.15입니다.

시험에 나오는 형태

  • 정의·선택: dynamic vs static, reversible reaction, 평형에서 [ ]가 같은지 (ch15-01)
  • N2O4/NO2\mathrm{N_2O_4/NO_2}N2​O4​/NO2​ 색·rate 이야기 (강의 슬라이드)
  • energy profile → KKK 크기 추론 (연습 3)

개념을 친절하게

가역 반응(reversible reaction): 생성물이 다시 반응물을 만들 수 있음 → 화학식 ⇌.

강의 핵심 그림: N2O4(g)⇌2NO2(g)\mathrm{N_2O_4(g) \rightleftharpoons 2NO_2(g)}N2​O4​(g)⇌2NO2​(g) (무색 ⇌ 갈색)

처음 (순수 N2O4\mathrm{N_2O_4}N2​O4​)진행 중평형
색무색갈색 진해짐일정
정반응 rate최대N2O4\mathrm{N_2O_4}N2​O4​↓로 감소= 역 rate
역반응 rate0NO2\mathrm{NO_2}NO2​↑로 증가= 정 rate
[ ]변함둘 다 변함시간에 따라 불변

**밀폐계(closed system)**에서만 위가 성립합니다.

슬라이드 Q: “평형에서 반응물·생성물 농도가 같은가?” → 아니오. 같아지는 것은 rate이고, 농도 비율은 **KKK**가 정합니다.

슬라이드: rate 상수의 몫 kf/krk_f/k_rkf​/kr​는 또 하나의 상수 → equilibrium constant KKK.

Equilibrium position: 혼합물이 반응물 쪽인지 생성물 쪽인지(조성). **KKK**는 그 위치를 숫자로 요약합니다.

ratefwd=raterev(평형; [ ]⋅분압은 보통 서로 다름)\mathrm{rate}_{\mathrm{fwd}} = \mathrm{rate}_{\mathrm{rev}} \quad\text{(평형; [ ]·분압은 보통 서로 다름)}ratefwd​=raterev​(평형; [ ]⋅분압은 보통 서로 다름)

생각 흐름 (시험장 루틴)

  1. 문제 읽기: “평형 정의인가, 농도 같음 함정인가, KKK·rate 구분인가?” 한 줄로 번역.
  2. 유형 판별: 정의(ch15-01a) / 그림(색·rate) / 서술(dynamic vs static).
  3. 쓸 개념 고르기 전 질문: “closed system인가?” “농도 불변 = rate equal인가?”
  4. 답 골격: dynamic → 양방향 계속 + macroscopic [ ] constant; ≠ 반응 정지, ≠ [reactant]=[product].
  5. 숫자 없으면 N2O4\mathrm{N_2O_4}N2​O4​ 예 한 줄: 색 안정 = rate equal, [ ]는 KKK로 따로.
  6. 검산: “static equilibrium(역학)”과 섞었는지 확인.
  7. 자주 하는 실수: 평형 = 농도 1:1 / 평형 = 반응 멈춤.

평형식 쓰기 · KcK_cKc​, KpK_pKp​, 균일·불균일

Law of mass action(질량작용의 법칙): 평형일 때 생성물/반응물을 화학양론 계수만큼 거듭제곱한 몫이 (같은 TTT에서) 상수 **KKK**입니다. 시험에서 가장 먼저 손이 가는 것은 식을 맞게 쓰는 것 — ch15-02, ch15-05, ch15-09 전부 여기서 시작합니다.

시험에 나오는 형태

  • KcK_cKc​ / KpK_pKp​ 식 작성 + homogeneous / heterogeneous (ch15-02, 연습 2)
  • CaCO3/CaO/CO2\mathrm{CaCO_3/CaO/CO_2}CaCO3​/CaO/CO2​, C(s)+H2O(g)\mathrm{C(s)+H_2O(g)}C(s)+H2​O(g) (강의 Ex.1–3, water gas summary)
  • 평형 농도·분압 넣어 KKK 계산 (ch15-04, ch15-05)

개념을 친절하게

일반: aA+bB⇌cC+dDa\mathrm{A}+b\mathrm{B}\rightleftharpoons c\mathrm{C}+d\mathrm{D}aA+bB⇌cC+dD

Homogeneous(균일): 반응 species가 한 상(예: 모두 기체).

Heterogeneous(불균일): 고체·액체·기체 등 여러 상.

Pure solid / pure liquid: activity ≈ 1 → 평형식에서 생략.

  • CaCO3(s)⇌CaO(s)+CO2(g)\mathrm{CaCO_3(s)\rightleftharpoons CaO(s)+CO_2(g)}CaCO3​(s)⇌CaO(s)+CO2​(g) → Kp=PCO2K_p=P_{\mathrm{CO_2}}Kp​=PCO2​​ (또는 Kc=[CO2]K_c=[\mathrm{CO_2}]Kc​=[CO2​]).
  • H2(g)+I2(s)⇌2HI(g)\mathrm{H_2(g)+I_2(s)\rightleftharpoons 2HI(g)}H2​(g)+I2​(s)⇌2HI(g) → I2(s)I_2(s)I2​(s) 생략 (연습 19c).

H2O\mathrm{H_2O}H2​O: H2O(l)\mathrm{H_2O(l)}H2​O(l) 용매는 보통 생략; **H2O(g)\mathrm{H_2O(g)}H2​O(g)**는 포함.

**같은 TTT**면 어디서 출발해도 같은 KKK (Haber 슬라이드).

KKK는 반응식 쓰는 방식(계수)에 따라 숫자가 달라짐 — 조성은 같아도 식을 2배하면 Knew=K2K_{\mathrm{new}}=K^2Knew​=K2 (조작은 별도 절).

공식 · 기호

Kc=[C]c[D]d[A]a[B]b,Kp=(PC)c(PD)d(PA)a(PB)bK_c = \frac{[\mathrm{C}]^c[\mathrm{D}]^d}{[\mathrm{A}]^a[\mathrm{B}]^b}, \qquad K_p = \frac{(P_{\mathrm{C}})^c(P_{\mathrm{D}})^d}{(P_{\mathrm{A}})^a(P_{\mathrm{B}})^b}Kc​=[A]a[B]b[C]c[D]d​,Kp​=(PA​)a(PB​)b(PC​)c(PD​)d​
