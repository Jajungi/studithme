Temperature threshold for limestone decomposition

석회석 분해의 임계 온도

For CaCO3(s)→CaO(s)+CO2(g)\mathrm{CaCO_3(s)\rightarrow CaO(s)+CO_2(g)}CaCO3​(s)→CaO(s)+CO2​(g), use the following data to estimate the temperature above which decomposition is spontaneous. Assume ΔH∘\Delta H^\circΔH∘ and ΔS∘\Delta S^\circΔS∘ are temperature-independent.

ΔHf∘\Delta H_f^\circΔHf∘​ (kJ/mol): CaCO3=−1207.1\mathrm{CaCO_3}=-1207.1CaCO3​=−1207.1, CaO=−635.5\mathrm{CaO}=-635.5CaO=−635.5, CO2=−393.5\mathrm{CO_2}=-393.5CO2​=−393.5.

S∘S^\circS∘ (J mol−1 K−1\mathrm{J\,mol^{-1}\,K^{-1}}Jmol−1K−1): CaCO3=92.88\mathrm{CaCO_3}=92.88CaCO3​=92.88, CaO=39.75\mathrm{CaO}=39.75CaO=39.75, CO2=213.6\mathrm{CO_2}=213.6CO2​=213.6.

Hints
  1. Calculate reaction ΔH∘\Delta H^\circΔH∘ and ΔS∘\Delta S^\circΔS∘ by products minus reactants.
  2. At the threshold, ΔG∘=0\Delta G^\circ=0ΔG∘=0 and T=ΔH∘/ΔS∘T=\Delta H^\circ/\Delta S^\circT=ΔH∘/ΔS∘.
한글 힌트
  1. 생성물−반응물로 반응 ΔH∘\Delta H^\circΔH∘와 ΔS∘\Delta S^\circΔS∘를 구한다.
  2. 임계점에서는 ΔG∘=0\Delta G^\circ=0ΔG∘=0, T=ΔH∘/ΔS∘T=\Delta H^\circ/\Delta S^\circT=ΔH∘/ΔS∘이다.
Worked solution
Answer
T≈1.11×103 KT\approx1.11\times10^3\,\mathrm{K}T≈1.11×103K (≈837∘C\approx837^\circ\mathrm{C}≈837∘C); spontaneous above this temperature
  1. Start with reaction enthalpy. ΔH∘=[−635.5+(−393.5)]−(−1207.1)=+178.1 kJ/mol\Delta H^\circ=[-635.5+(-393.5)]-(-1207.1)=+178.1\,\mathrm{kJ/mol}ΔH∘=[−635.5+(−393.5)]−(−1207.1)=+178.1kJ/mol.
  2. Calculate reaction entropy. ΔS∘=(39.75+213.6)−92.88=+160.47 J mol−1 K−1=0.16047 kJ mol−1 K−1\Delta S^\circ=(39.75+213.6)-92.88=+160.47\,\mathrm{J\,mol^{-1}\,K^{-1}}=0.16047\,\mathrm{kJ\,mol^{-1}\,K^{-1}}ΔS∘=(39.75+213.6)−92.88=+160.47Jmol−1K−1=0.16047kJmol−1K−1.
  3. Set the boundary condition. At the crossover, 0=ΔH∘−TΔS∘0=\Delta H^\circ-T\Delta S^\circ0=ΔH∘−TΔS∘, so T=ΔH∘/ΔS∘T=\Delta H^\circ/\Delta S^\circT=ΔH∘/ΔS∘.
  4. Solve. T=(178.1 kJ/mol)/(0.16047 kJ mol−1 K−1)=1.11×103 KT=(178.1\,\mathrm{kJ/mol})/(0.16047\,\mathrm{kJ\,mol^{-1}\,K^{-1}})=1.11\times10^3\,\mathrm{K}T=(178.1kJ/mol)/(0.16047kJmol−1K−1)=1.11×103K, about 837∘C837^\circ\mathrm{C}837∘C.
  5. Determine the favorable side. Both ΔH∘\Delta H^\circΔH∘ and ΔS∘\Delta S^\circΔS∘ are positive, so the −TΔS-T\Delta S−TΔS term wins at high temperature; decomposition is spontaneous above about 1110 K1110\,\mathrm{K}1110K.
  6. Takeaway. For ΔH>0\Delta H>0ΔH>0 and ΔS>0\Delta S>0ΔS>0, a process is favored only above the temperature where TΔS=ΔHT\Delta S=\Delta HTΔS=ΔH.
