Which statement about the common-ion effect is correct?

공통 이온 효과에 관한 올바른 설명

Which of these statements about the common-ion effect is most correct?

(a) The solubility of a salt MA is decreased in a solution that already contains either M+\mathrm{M^+}M+ or A−\mathrm{A^-}A−.

(b) Common ions alter the equilibrium constant for the reaction of an ionic solid with water.

(c) The common-ion effect does not apply to unusual ions like SO32−\mathrm{SO_3^{2-}}SO32−​.

(d) The solubility of a salt MA is affected equally by the addition of either A−\mathrm{A^-}A− or a noncommon ion.
한글
공통 이온 효과에 관한 다음 설명 중 가장 올바른 것은?

(a) 염 MA의 용해도는 M+\mathrm{M^+}M+ 또는 A−\mathrm{A^-}A−가 이미 들어 있는 용액에서 감소한다.

(b) 공통 이온은 이온성 고체가 물과 반응하는 평형상수를 바꾼다.

(c) 공통 이온 효과는 SO32−\mathrm{SO_3^{2-}}SO32−​ 같은 특이한 이온에는 적용되지 않는다.

(d) 염 MA의 용해도는 A−\mathrm{A^-}A−를 넣을 때와 공통이 아닌 이온을 넣을 때 똑같이 영향을 받는다.

  2. An equilibrium constant depends only on temperature.
한글 힌트
  1. 용해 평형 MA(s)⇌M++A−\mathrm{MA(s)\rightleftharpoons M^+ + A^-}MA(s)⇌M++A−를 쓰고 Le Chatelier 원리를 적용한다.
  2. 평형상수는 온도에만 의존한다.
Worked solution
Answer
(a)
  1. Write the equilibrium. MA(s)⇌M+(aq)+A−(aq)\mathrm{MA(s)\rightleftharpoons M^+(aq)+A^-(aq)}MA(s)⇌M+(aq)+A−(aq), Ksp=[M+][A−]K_{sp}=[\mathrm{M^+}][\mathrm{A^-}]Ksp​=[M+][A−].
  2. Test (a). Adding either product ion raises its concentration, so the equilibrium shifts left and less MA dissolves. This is exactly the common-ion effect — true.
  3. Test (b). KspK_{sp}Ksp​ is a constant at fixed temperature; added ions change concentrations, not KspK_{sp}Ksp​ — false.
  4. Test (c). The effect applies to any ion that appears in the equilibrium, including SO32−\mathrm{SO_3^{2-}}SO32−​ — false.
  5. Test (d). A noncommon ion does not enter the KspK_{sp}Ksp​ expression and does not suppress solubility in the same way — false.
  6. Takeaway. Common-ion effect = Le Chatelier shift of the solubility equilibrium; KspK_{sp}Ksp​ itself is unchanged.
