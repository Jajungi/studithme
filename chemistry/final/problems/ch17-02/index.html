Worked solution
Answer
pH=4.80\mathrm{pH}=4.80pH=4.80
  1. Start with strong-base stoichiometry. Added hydroxide is nOH−=(0.0050 L)(4.0 mol/L)=0.020 moln_{\mathrm{OH^-}}=(0.0050\,\mathrm{L})(4.0\,\mathrm{mol/L})=0.020\,\mathrm{mol}nOH−​=(0.0050L)(4.0mol/L)=0.020mol.
  2. Neutralize the weak acid. OH−\mathrm{OH^-}OH− consumes 0.020 mol0.020\,\mathrm{mol}0.020mol CH3COOH\mathrm{CH_3COOH}CH3​COOH and forms the same amount of CH3COO−\mathrm{CH_3COO^-}CH3​COO−.
  3. Find post-reaction amounts. Acid: 0.300−0.020=0.280 mol0.300-0.020=0.280\,\mathrm{mol}0.300−0.020=0.280mol; base: 0.300+0.020=0.320 mol0.300+0.020=0.320\,\mathrm{mol}0.300+0.020=0.320mol.
  4. Calculate pKapK_apKa​. pKa=−log⁡(1.80×10−5)=4.74pK_a=-\log(1.80\times10^{-5})=4.74pKa​=−log(1.80×10−5)=4.74.
  5. Apply Henderson–Hasselbalch using mole ratio. Because both species share the same final volume, pH=4.74+log⁡(0.320/0.280)=4.80\mathrm{pH}=4.74+\log(0.320/0.280)=4.80pH=4.74+log(0.320/0.280)=4.80.
  6. Takeaway. When strong acid or base is added to a buffer, do reaction stoichiometry first and equilibrium second.
