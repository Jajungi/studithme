공통 이온 효과 · Common-Ion Effect

개념

약전해질의 평형에 이미 포함된 이온을 강전해질로 넣으면 평형이 그 이온을 소모하는 방향으로 이동해 이온화가 억제됩니다.

CH3COOH⇌H++CH3COO−\mathrm{CH_3COOH\rightleftharpoons H^+ + CH_3COO^-}CH3​COOH⇌H++CH3​COO−

CH3COONa\mathrm{CH_3COONa}CH3​COONa를 넣으면 CH3COO−\mathrm{CH_3COO^-}CH3​COO−가 증가해 왼쪽으로 이동하고 [H+][\mathrm{H^+}][H+]가 감소하여 pH가 올라갑니다. NH3/NH4+\mathrm{NH_3/NH_4^+}NH3​/NH4+​에서는 NH4Cl\mathrm{NH_4Cl}NH4​Cl 첨가가 [OH−][\mathrm{OH^-}][OH−]를 낮춰 pH를 내립니다. 평형상수 자체는 온도가 같으면 변하지 않습니다.

공식

공통 이온 농도를 ICE의 Initial에 넣습니다.

Ka=[H+][A−][HA],Kb=[BH+][OH−][B]K_a=\frac{[\mathrm{H^+}][\mathrm{A^-}]}{[\mathrm{HA}]},\qquad K_b=\frac{[\mathrm{BH^+}][\mathrm{OH^-}]}{[\mathrm B]}Ka​=[HA][H+][A−]​,Kb​=[B][BH+][OH−]​

영어 용어

  • common-ion effect — 공통 이온 효과
  • suppresses ionization — 이온화를 억제한다
  • weak electrolyte / strong electrolyte — 약전해질 / 강전해질
  • shift to the left — 왼쪽으로 이동

미니 예제

0.30 M CH3COOH\mathrm{CH_3COOH}CH3​COOH와 0.30 M CH3COO−\mathrm{CH_3COO^-}CH3​COO−:

[H+]≈Ka[HA][A−]=1.8×10−5,pH=4.74.[\mathrm{H^+}]\approx K_a\frac{[\mathrm{HA}]}{[\mathrm{A^-}]}=1.8\times10^{-5}, \quad \mathrm{pH}=4.74.[H+]≈Ka​[A−][HA]​=1.8×10−5,pH=4.74.

함정

함정올바른 생각
common ion이 KaK_aKa​를 바꿈KaK_aKa​는 고정, 평형 조성이 변함
NaCl도 HF의 공통 이온HF에는 F−\mathrm{F^-}F−를 주는 NaF
0.10 M HCl + 약산에서 약산 기여 큼H⁺가 약산 이온화를 억제

완충 용액 · Buffers

개념

완충 용액은 약산과 짝염기(또는 약염기와 짝산)가 둘 다 상당량 있어 소량의 강산·강염기 첨가에 pH 변화를 작게 만듭니다.

  • 첨가한 H+\mathrm{H^+}H+: A−+H+→HA\mathrm{A^-+H^+\to HA}A−+H+→HA
  • 첨가한 OH−\mathrm{OH^-}OH−: HA+OH−→A−+H2O\mathrm{HA+OH^-\to A^-+H_2O}HA+OH−→A−+H2​O

직접 약산+염을 섞거나, 약산의 약 절반을 강염기로 중화해 만들 수 있습니다.

공식

pH=pKa+log⁡[base][acid]\mathrm{pH=p}K_a+\log\frac{[\mathrm{base}]}{[\mathrm{acid}]}pH=pKa​+log[acid][base]​

같은 용액 부피를 공유하면 농도 대신 mol 비를 써도 됩니다. [base]=[acid][\mathrm{base}]=[\mathrm{acid}][base]=[acid]이면 pH=pKa\mathrm{pH=p}K_apH=pKa​입니다.

완충 범위(range)는 대략 pKa±1\mathrm{p}K_a\pm1pKa​±1, 완충 용량(capacity)은 두 성분의 절대량·농도가 클수록 큽니다. 농도를 둘 다 2배로 하면 pH 비는 그대로지만 용량은 증가합니다.

영어 용어

  • buffer / buffered solution — 완충 용액
  • Henderson–Hasselbalch equation — 헨더슨–하셀바흐 식
  • buffer capacity / pH range — 완충 용량 / 유효 pH 범위
  • conjugate acid–base pair — 짝산–짝염기 쌍

미니 예제

Ka=1.4×10−4K_a=1.4\times10^{-4}Ka​=1.4×10−4인 젖산 0.12 M / 젖산염 0.10 M:

pH=3.85+log⁡(0.10/0.12)=3.77.\mathrm{pH}=3.85+\log(0.10/0.12)=3.77.pH=3.85+log(0.10/0.12)=3.77.

함정

함정올바른 생각
약산만 있으면 buffer짝염기도 상당량 필요
HCl + NaCl buffer강산과 중성 염은 buffer 아님
같은 비율이면 용량도 같음pH는 같아도 진한 쪽이 capacity 큼

완충 용액에 강산·강염기 첨가 · Adding Strong Acid/Base

개념

강산·강염기를 완충 용액에 넣으면 곧바로 Henderson 식에 넣지 않습니다. 먼저 완결되는 중화 화학양론, 그다음 남은 약산/짝염기로 평형 계산을 합니다.

공식

강염기 첨가:

HA+OH−→A−+H2O\mathrm{HA+OH^-\to A^-+H_2O}HA+OH−→A−+H2​O

강산 첨가:

A−+H+→HA\mathrm{A^-+H^+\to HA}A−+H+→HA

중화 후 두 성분이 모두 남아 있을 때만 Henderson–Hasselbalch를 사용합니다. 강산·강염기가 과량이면 남은 강전해질이 pH를 결정합니다.

영어 용어

  • stoichiometry first, equilibrium second — 화학양론 먼저, 평형 다음
  • neutralization — 중화
  • buffer capacity exceeded — 완충 용량을 초과함
  • remaining moles — 반응 후 남은 mol

미니 예제

0.300 mol HA와 0.300 mol A⁻에 0.020 mol NaOH: HA 0.2800.2800.280 mol, A⁻ 0.3200.3200.320 mol. pKa=4.74pK_a=4.74pKa​=4.74라면

pH=4.74+log⁡(0.320/0.280)=4.80.\mathrm{pH}=4.74+\log(0.320/0.280)=4.80.pH=4.74+log(0.320/0.280)=4.80.

산–염기 적정 · Acid–Base Titrations

개념

당량점(equivalence point)은 산과 염기가 화학양론적으로 정확히 반응한 점입니다. 종말점(endpoint)은 지시약 색이 바뀐 관측점입니다.

강산–강염기 적정은 당량점 pH가 25°C에서 7입니다. 약산–강염기 적정은 구간별 풀이가 달라집니다.

  1. 초기: 약산 KaK_aKa​ ICE
  2. 당량점 전: 중화 후 HA/A⁻ buffer, Henderson
  3. 반당량점: [HA]=[A−][\mathrm{HA}]=[\mathrm{A^-}][HA]=[A−], pH=pKa\mathrm{pH=p}K_apH=pKa​
  4. 당량점: A⁻ 가수분해, Kb=Kw/KaK_b=K_w/K_aKb​=Kw​/Ka​, pH >7>7>7
  5. 당량점 후: 과량 OH−\mathrm{OH^-}OH−가 pH 결정

약염기–강산은 거울상이며 당량점 pH <7<7<7입니다.

공식

당량점 부피는 반응식의 mol 비로 결정합니다.

n=MVn=MVn=MV

지시약은 당량점 주변의 가파른 pH 변화 범위와 색 변화 범위가 겹치는 것을 고릅니다.

영어 용어

  • titrant / analyte — 적정제 / 분석물
  • titration curve — 적정 곡선
  • equivalence point / endpoint — 당량점 / 종말점
  • half-equivalence point — 반당량점
  • acid–base indicator — 산–염기 지시약

함정

함정올바른 생각
모든 당량점 pH=7강산–강염기만
반당량점 pH=7약산 적정은 pH=pKa
전 구간 Henderson초기·당량·후당량은 다른 계산
당량점 = 지시약 색 변화endpoint는 실험적 근사

용해도 평형과 KspK_{sp}Ksp​ · Solubility Equilibria

개념

난용성 이온 고체의 포화 용액에서는 용해와 석출이 동적 평형입니다. 고체는 평형식에서 생략하고, 용액 이온 농도를 계수만큼 지수로 올립니다.

Ba3(PO4)2(s)⇌3Ba2++2PO43−\mathrm{Ba_3(PO_4)_2(s)\rightleftharpoons3Ba^{2+}+2PO_4^{3-}}Ba3​(PO4​)2​(s)⇌3Ba2++2PO43−​ Ksp=[Ba2+]3[PO43−]2K_{sp}=[\mathrm{Ba^{2+}}]^3[\mathrm{PO_4^{3-}}]^2Ksp​=[Ba2+]3[PO43−​]2

molar solubility sss는 용해된 화학식 단위의 mol/L입니다. KspK_{sp}Ksp​가 작다고 무조건 molar solubility가 더 작은 것은 아닙니다. 화학양론이 같은 염끼리만 직접 비교하세요.

공식

형태이온 농도KspK_{sp}Ksp​
MXs,ss,ss,ss2s^2s2
MX₂s,2ss,2ss,2s4s34s^34s3
M₃X₂3s,2s3s,2s3s,2s108s5108s^5108s5

g/L가 주어지면 먼저 molar mass로 mol/L로 바꿉니다.

영어 용어

  • solubility product (KspK_{sp}Ksp​) — 용해도곱
  • molar solubility — 몰 용해도
  • saturated / unsaturated — 포화 / 불포화
  • sparingly soluble — 난용성인

미니 예제

Mg(OH)2\mathrm{Mg(OH)_2}Mg(OH)2​의 Ksp=1.8×10−11K_{sp}=1.8\times10^{-11}Ksp​=1.8×10−11:

Ksp=s(2s)2=4s3⇒s=1.7×10−4 M.K_{sp}=s(2s)^2=4s^3\Rightarrow s=1.7\times10^{-4}\ \mathrm M.Ksp​=s(2s)2=4s3⇒s=1.7×10−4 M.

함정

함정올바른 생각

계수를 앞에 곱함계수는 지수, 농도에는 stoichiometry
KspK_{sp}Ksp​가 작은 염이 무조건 덜 녹음ion ratio를 고려

용해도에 영향을 주는 요인 · Factors Affecting Solubility

개념

온도가 고정되면 KspK_{sp}Ksp​는 그대로지만 다른 평형이 자유 이온을 제거하거나 더하면 용해도는 달라집니다.

  • 공통 이온: 생성물 이온 추가 → 용해도 감소
  • pH: OH−\mathrm{OH^-}OH− 또는 약산의 짝염기(F−,CO32−,PO43−\mathrm{F^-,CO_3^{2-},PO_4^{3-}}F−,CO32−​,PO43−​)를 가진 염은 산에서 더 잘 녹음
  • 복합 이온: 리간드가 금속 이온을 묶어 자유 금속 농도를 낮추면 더 녹음
  • 양쪽성 수산화물: Al(OH)3,Zn(OH)2\mathrm{Al(OH)_3,Zn(OH)_2}Al(OH)3​,Zn(OH)2​ 등은 강산과 강염기 모두에 녹을 수 있음

공식

Ag++2NH3⇌Ag(NH3)2+,Kf\mathrm{Ag^+ +2NH_3\rightleftharpoons Ag(NH_3)_2^+},\qquad K_fAg++2NH3​⇌Ag(NH3​)2+​,Kf​

AgCl\mathrm{AgCl}AgCl 용해와 합치면 전체 상수는

Koverall=KspKf.K_{\mathrm{overall}}=K_{sp}K_f.Koverall​=Ksp​Kf​.

  • ligand / complex ion — 리간드 / 착이온
  • amphoteric hydroxide — 양쪽성 수산화물
  • free metal-ion concentration — 자유 금속 이온 농도

침전과 선택적 분리 · Precipitation & Separation

개념

현재 이온 농도를 KspK_{sp}Ksp​ 식에 넣은 값이 ion product QQQ입니다.

  • Q<KspQ<K_{sp}Q<Ksp​: 불포화, 침전 없음
  • Q=KspQ=K_{sp}Q=Ksp​: 포화 평형
  • Q>KspQ>K_{sp}Q>Ksp​: 침전이 생겨 QQQ가 KspK_{sp}Ksp​로 감소

두 용액을 섞으면 반드시 각 이온 mol / 전체 부피로 희석 후 QQQ를 계산합니다. 선택적 침전에서는 침전을 시작하는 데 필요한 시약 이온 농도가 더 작은 염이 먼저 석출됩니다.

공식

예: M(OH)2\mathrm{M(OH)_2}M(OH)2​가 막 침전할 때

[OH−]min⁡=Ksp[M2+].[\mathrm{OH^-}]_{\min}=\sqrt{\frac{K_{sp}}{[\mathrm{M^{2+}}]}}.[OH−]min​=[M2+]Ksp​​​.

영어 용어

  • ion product (QQQ) — 이온곱
  • precipitate / precipitation — 침전 / 침전 반응
  • selective precipitation — 선택적 침전
  • minimum concentration to begin precipitation — 침전 시작 최소 농도
  • qualitative analysis — 정성 분석

완충 pH

1. Buffer 판별과 pH

  1. 약산/짝염기 또는 약염기/짝산이 둘 다 남는지 확인한다.
  2. 혼합 문제면 먼저 mol로 중화한다.
  3. 두 성분이 남으면 pH=pKa+log⁡(nbase/nacid)\mathrm{pH=p}K_a+\log(n_{\mathrm{base}}/n_{\mathrm{acid}})pH=pKa​+log(nbase​/nacid​).
  4. 비율이 0.10.10.1–101010인지 보아 유효 범위를 확인한다.
  5. 강산·강염기가 남으면 buffer 식을 중단한다.
적정 구간

2. 적정 pH

  1. 산·염기 mol을 비교해 초기/전당량/당량/후당량 구간을 정한다.
  2. 약산 초기 → KaK_aKa​ ICE.
  3. 전당량 → 중화 후 Henderson; 반당량이면 pH=pKa.
  4. 당량 → 생성된 짝 이온의 가수분해.
  5. 후당량 → 과량 strong titrant / 전체 부피.
Ksp·용해도

3. Ksp↔sK_{sp}\leftrightarrow sKsp​↔s

  1. 균형 용해식을 쓴다.
  2. 고체를 뺀 KspK_{sp}Ksp​ 식을 쓴다.
  3. molar solubility를 sss로 두고 각 이온을 계수×sss로 표시한다.
  4. KspK_{sp}Ksp​를 풀고 필요하면 g/L로 바꾼다.
  5. common ion이 있으면 Initial 농도를 포함하고 xxx가 작은지 검산한다.
침전 Q

4. 침전 여부와 선택적 침전

  1. 가능한 난용성 염을 쓴다.
  2. 혼합 후 각 이온 mol을 총부피로 나눈다.
  3. QQQ를 KspK_{sp}Ksp​와 같은 형태로 계산한다.
  4. Q>KspQ>K_{sp}Q>Ksp​면 침전.
  5. 선택적 침전은 각 염의 시작 임계 농도를 구해 작은 쪽을 고른다.
용해도 변화

5. 공통 이온·pH·착이온

  1. 공통 이온인가 → solubility 감소.
  2. 음이온이 염기성인가 → 산이 제거하므로 산에서 증가.
  3. 리간드가 금속과 큰 KfK_fKf​ 착물을 만드는가 → 증가.
  4. 양쪽성 수산화물인가 → 강염기에서도 착물로 용해 가능.
  5. 모든 경우 온도 일정이면 KspK_{sp}Ksp​ 자체는 일정하다.
