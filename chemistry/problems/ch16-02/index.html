[H⁺] when 10× [OH⁻]

Worked solution
Answer
[H⁺]=3.16×10⁻⁷ M, acidic
  1. Given relation. [H+]=10[OH−][\mathrm{H^+}] = 10[\mathrm{OH^-}][H+]=10[OH−] at 25∘C25^\circ\mathrm{C}25∘C with Kw=[H+][OH−]=1.0×10−14K_w = [\mathrm{H^+}][\mathrm{OH^-}] = 1.0\times 10^{-14}Kw​=[H+][OH−]=1.0×10−14.
  2. Substitute. [H+]([H+]/10)=10−14[\mathrm{H^+}]([\mathrm{H^+}]/10) = 10^{-14}[H+]([H+]/10)=10−14 → [H+]2=10−13[\mathrm{H^+}]^2 = 10^{-13}[H+]2=10−13.
  3. Solve for [H+][\mathrm{H^+}][H+]. [H+]=10−13=3.16×10−7 M[\mathrm{H^+}] = \sqrt{10^{-13}} = 3.16\times 10^{-7}\,\mathrm{M}[H+]=10−13​=3.16×10−7M.
  4. Classify solution. [H+]>[OH−][\mathrm{H^+}] > [\mathrm{OH^-}][H+]>[OH−] (by factor 10) and [H+]>10−7 M[\mathrm{H^+}] > 10^{-7}\,\mathrm{M}[H+]>10−7M → acidic.
