Define each term and give an example:

(a) dynamic equilibrium
(b) KcK_cKc​
(c) reaction quotient QcQ_cQc​

Hints
  1. QQQ uses current amounts; KKK uses equilibrium amounts.
한글 힌트
  1. QQQ는 현재 양, KKK는 평형 양.
Worked solution
Answer
dynamic eq / Kc / Qc / Le Châtelier
  1. (a) Dynamic equilibrium: Forward and reverse reactions occur at equal rates; macroscopic concentrations (or pressures) stay constant though molecules keep reacting.
  2. (b) KcK_cKc​: Equilibrium constant from molar concentrations (or activities) for a balanced equation; fixed at a given TTT.
  3. (c) Reaction quotient QcQ_cQc​: Same mathematical form as KcK_cKc​ but uses current (not necessarily equilibrium) concentrations; predicts shift direction.
  4. (d) Le Châtelier’s principle: If a system at equilibrium is disturbed, it shifts to partially counteract the disturbance (e.g., add reactant → forward shift).
한글 답
동적 평형 / Kc / Qc / 르 샤틀리에
한글 해설
  1. (a) 동적 평형: 정반응·역반응 속도가 같아 거시적 농도(또는 압력)는 일정; 분자 수준에서는 계속 반응한다.
  2. (b) KcK_cKc​: 균형 반응식에 대한 평형 농도(또는 활도)로부터 정의; 주어진 TTT에서 정해진 값.
  3. (c) 반응 지수 QcQ_cQc​: KcK_cKc​와 같은 수식 형태이나 현재(평형이 아닐 수 있음) 농도 사용; 이동 방향 예측.
  4. (d) 르 샤틀리에 원리: 평형 상태에 교란을 주면, 계가 그 교란을 부분적으로 상쇄하는 쪽으로 이동(예: 반응물 추가 → 정반응).
