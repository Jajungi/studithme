Order from [A] vs time graph

[A]–시간 그래프로 차수

The concentration of A was recorded versus time as it decomposed to B (see graph). Is the decomposition zero-, first-, or second-order? Explain.
한글
A가 B로 분해될 때 농도–시간 그래프가 주어졌다. 0차·1차·2차 중 무엇인가? 근거를 설명하라.

Hints
  1. Check whether half-life is constant (first order).
  2. Zero order: [A] vs t is linear; second order: 1/[A] vs t is linear.
한글 힌트
  1. 반감기가 일정한지 본다(1차).
  2. 0차: [A]–t가 직선; 2차: 1/[A]–t가 직선.
Worked solution
Answer
First order (constant half-life on the graph)
  1. Inspect curvature. A decaying curve (steep then flattening) is not zero order (zero order would be a straight line down).
  2. Half-life test. Read times when [A][A][A] halves repeatedly. If t1/2t_{1/2}t1/2​ is roughly constant → first order.
  3. If t1/2t_{1/2}t1/2​ lengthens as [A][A][A] drops → second order (or higher).
  4. Conclusion. For the practice graph, constant half-life ≈ 60 min → first-order decomposition.
한글 답
1차 (그래프에서 반감기 일정)
한글 해설
  1. 곡선 모양. 아래로 볼록하게 감쇠하면 0차(직선)는 아니다.
  2. 반감기. [A][A][A]가 절반이 되는 시간이 거의 같으면 1차.
  3. 반감기가 길어지면 2차(또는 그 이상)를 의심.
  4. 결론. 연습 그래프는 반감기 ≈ 일정 → 1차.
