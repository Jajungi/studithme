Ch.13 용액 · Solutions

용어 · 용해

  • Solvent / solute; saturated = dissolution ⇌ crystallization (dynamic equilibrium). Supersaturated is metastable.용매·용질. 포화 = 용해↔석출 동적 평형. 과포화는 불안정.
  • Like dissolves like: match polarity / IMF (dispersion, dipole–dipole, H-bond, ion–dipole).비슷한 극성·IMF끼리 잘 녹음.
  • Solids: TTT↑ often solubility↑. Gases: TTT↑ solubility↓; PPP↑ (Henry) solubility↑.고체는 보통 TTT↑ 용해도↑. 기체는 TTT↑↓, 부분압↑↑.

농도

  • MMM changes with TTT (volume); mmm essentially does not.온도↑ → 부피↑ → MMM↓; mmm은 거의 불변.

총괄성

  • Depend on particle count: vapor-pressure lowering, ΔTb\Delta T_bΔTb​, ΔTf\Delta T_fΔTf​, Π\PiΠ. Use iii for electrolytes (ideal: nonelectrolyte 1, NaCl 2, CaCl₂ 3; real iii often lower).입자 수에만 의존. 전해질은 iii.

Ch.15 평형 · Equilibrium

동적 평형 · K

  • Forward rate = reverse rate; concentrations constant, reactions continue (e.g. N2O4⇌2NO2\mathrm{N_2O_4\rightleftharpoons 2NO_2}N2​O4​⇌2NO2​).정·역 속도 같음. 농도는 일정해도 반응은 계속.
  • Write KcK_cKc​ / KpK_pKp​ from stoichiometry; omit pure solids/liquids. Homogeneous vs heterogeneous.고체·순수 액체 제외. 균일/불균일 구분.
  • K≫1K\gg 1K≫1 mostly products; K≪1K\ll 1K≪1 mostly reactants. KKK is for a written equation at fixed TTT.K≫1K\gg 1K≫1 생성물 우세, ≪1\ll 1≪1 반응물 우세.

Q · ICE · K 조작

  • QQQ uses current amounts → compare to KKK for direction.QQQ vs KKK로 이동 방향.
  • ICE for equilibrium [ ][\ ][ ] or KKK; check approximations (e.g. 5% rule).ICE로 평형 농도·KKK. 근사 타당성 확인.
  • Reverse → 1/K1/K1/K; ×n → KnK^nKn; add reactions → multiply KKK values.역·배수·합성 시 KKK 조작.

Le Châtelier

  • Concentration / PPP–VVV (gases): shift position, KKK unchanged (fixed TTT).
  • Temperature: only factor that changes KKK (endo: TTT↑ ⇒ KKK↑).
  • Catalyst: faster equilibration, same KKK and composition.
  • Inert gas at constant VVV: usually no shift.

농도·압력은 이동만, KKK는 그대로. 온도만 KKK 변경. 촉매는 도달만 빠르게. 부피 일정 불활성 기체 → 보통 이동 없음.

Ch.16 산–염기 · Acid–Base

정의

TheoryAcidBase
Arrhenius↑[H⁺] in water↑[OH⁻]
Brønsted–LowryH⁺ donorH⁺ acceptor
Lewise⁻-pair acceptore⁻-pair donor

Water amphiprotic. Conjugate pairs differ by one H⁺. Every Brønsted acid is Lewis; not every Lewis acid is Brønsted.

물 = 양쪽성. 짝쌍 = H⁺ 하나 차이. Brønsted ⊂ Lewis(산 쪽).

Kw · 강/약 · ICE

  • 25 °C: Kw=10−14K_w=10^{-14}Kw​=10−14, pH + pOH = 14. Strong → complete ionization (no ICE). Weak → ICE with KaK_aKa​ or KbK_bKb​.강전해질은 ICE 없음. 약은 ICE.
  • % ionization ≈ 100Ka/C100\sqrt{K_a/C}100Ka​/C​ (weak acid, same CCC: smaller KaK_aKa​ → lower %). Dilution ↑ % ionization.같은 CCC면 KaK_aKa​ 작을수록 %↓. 묽히면 %↑.
  • KaKb=KwK_a K_b = K_wKa​Kb​=Kw​ for a conjugate pair.짝쌍에서만 KaKb=KwK_a K_b=K_wKa​Kb​=Kw​.

염 수용액 pH

  1. Split into cation + anion.
  2. Cation: Na⁺, K⁺, Ba²⁺… → spectator; NH₄⁺ → acidic; Fe³⁺, Al³⁺… → acidic (hydrolysis).
  3. Anion: Cl⁻, NO₃⁻, ClO₄⁻… → spectator; CH₃COO⁻, CN⁻, CO₃²⁻… → basic; HCO₃⁻, H₂PO₄⁻… → compare KaK_aKa​ vs KbK_bKb​.
  4. One active ion wins; both spectators → neutral; both active → compare strengths.

예: NH₄Br 산성, FeCl₃ 산성, Na₂CO₃ 염기성, KClO₄ 중성. 강산·강염기 목록을 먼저 외우면 빠름.
