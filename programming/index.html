01

출력과 입력Output and input

계산이 끝나도 결과는 표준 출력에 스스로 나타나지 않는다. 보여줄 때만 print를 호출한다.A finished calculation does not appear by itself. Call print only when the result should be shown.

print

함수function

특징Behavior

print는 인자(argument)를 표준 출력에 한 줄(또는 지정한 끝 문자)로 기록하는 함수다. 화면에 글자가 나타나는 일과, 호출이 돌려주는 값은 별개다. 호출의 반환값은 항상 None이다.

print is a function that writes its arguments to standard output, ending with a newline by default. What appears on the screen is separate from the value the call returns. The return value is always None.

사용Usage

print(값들, sep=" ", end=" ")

여러 값은 쉼표로 나란히 둔다. 기본으로 값 사이에는 공백 하나(sep)가 들어가고, 마지막에는 줄바꿈(end)이 붙는다. 수와 문자열을 한 호출에 함께 둘 수 있다. 문자열과 수를 +로 이어 붙이려면 먼저 str로 맞춰야 한다.

Pass several values separated by commas. By default one space (sep) goes between values and a newline (end) follows the last one. A number and a string may share one call. To join a string and a number with +, convert with str first.

보충Notes

x = print(1)처럼 대입하면 화면에는 1이 나오지만 x에는 None이 남는다. reverse는 print의 매개변수가 아니라서 print(lst, reverse=True)는 TypeError다. 역순으로 보여 주려면 sorted나 슬라이스를 쓴다.

With x = print(1), 1 still appears on the screen, but x stores None. reverse is not a parameter of print, so print(lst, reverse=True) raises TypeError. To show a reversed order, use sorted or a slice.

예시Example

b = 2
print("b =", float(b))
# b = 2.0

쉼표로 나눈 두 인자가 공백 하나로 이어져 한 줄에 출력된다.

The two comma-separated arguments are joined by one space on a single line.

print(1, 2, sep="-")
# 1-2
print("A", end="")
print("B")
# AB

sep으로 가운데 글자를 바꾸고, end를 빈 문자열로 두면 다음 print가 같은 줄에 이어 쓴다.

sep changes the middle text, and an empty end lets the next print continue on the same line.

x = print(1)
print(x)
# 1
# None

첫 줄은 print가 화면에 쓴 1이고, 둘째 줄은 반환값 None을 다시 출력한 것이다.

The first line is the 1 that print wrote; the second line is the return value None printed again.

input

함수function

특징Behavior

input은 키보드(표준 입력)에서 Enter 전까지의 한 줄을 읽어, 그 글자들을 문자열(str)로 반환하는 함수다. 화면에 숫자처럼 보여도 자료형은 문자열이므로, 바로 더하기·곱하기 같은 수 연산에 넣지 않는다.

input reads one line from the keyboard (standard input) up to Enter and returns those characters as a string (str). Even when the line looks like a number, its type is str, so it is not used directly in arithmetic.

사용Usage

input("안내 문구")

괄호 안의 안내 문구는 선택이다. 있으면 입력 전에 그 글자가 화면에 나온다. 반환값에는 줄바꿈 문자가 포함되지 않는다. 정수로 쓰려면 n = int(input(...))처럼 변환 결과를 이름에 담는다.

The prompt inside the parentheses is optional. When present, it is shown before the user types. The returned string does not include the newline. To use the value as an integer, store a conversion such as n = int(input(...)).

보충Notes

int는 정수 모양의 문자열만 받는다. "abc"나 "9.0"을 그대로 int에 넣으면 ValueError다. 소수 형태 글자는 float를 거친 뒤 필요하면 다시 int로 만든다.

int accepts only a string that already looks like an integer. Passing "abc" or "9.0" straight to int raises ValueError. A decimal-looking string goes through float first, then int if needed.

예시Example

text = input("Enter a number: ")
# 키보드에 4 와 Enter
print(text)       # 4  (글자)
print(type(text)) # <class 'str'>

입력한 4는 글자 "4"다. type으로 보면 str이다.

The typed 4 is the characters "4". type shows str.

n = int(input("Enter a number: "))
# 4 입력
print(n + 1)
# 5

int로 바꾼 뒤에야 4 + 1이 5가 된다. text에만 두고 int를 빼먹으면 문자열 연산이 된다.

Only after int does 4 + 1 become 5. Leaving the value as text without int keeps string behavior.

f-string

표기notation

특징Behavior

f-string은 문자열을 조립하는 표기다. 따옴표 앞에 f를 붙이고, 중괄호 { } 안에 이름이나 식을 두면, 그 식을 계산한 결과가 그 자리의 글자가 된다. 이 표기만으로는 화면에 출력되지 않는다. 보여줄 때는 print에 넘긴다.

An f-string is notation that builds a string. With f before the quotes, a name or expression inside braces { } is evaluated and its result becomes text in that place. The notation alone does not print. Pass the result to print to show it.

사용Usage

f"글자 {식} 글자"

중괄호 안에는 변수 이름뿐 아니라 연산·비교·함수 호출도 둘 수 있다. 바깥 따옴표와 안쪽 문자열 따옴표가 겹치지 않게 고른다. 형식 지정(소수 자리 등)은 수업의 str.format과 비슷한 자리에도 쓸 수 있으나, 이 단원 예제는 식 삽입에 초점을 둔다.

Braces may hold a variable name, an operation, a comparison, or a call. Choose quote marks so the outer quotes do not clash with quotes inside. Format specs (such as decimal places) can appear in a similar slot to str.format, but the examples here focus on inserting expressions.

보충Notes

f-string의 결과는 하나의 str 값이다. 대입하면 그 문자열이 이름에 남고, print 없이도 다른 함수 인자로 넘길 수 있다.

The result of an f-string is one str value. Assigned to a name it stays available, and it can be passed to another function without printing.

예시Example

n = 4
msg = f"n={n}"
print(msg)
# n=4

중괄호 안의 n이 4로 바뀌어 문자열 "n=4"가 된다.

The n inside the braces becomes 4, so the string is "n=4".

one, two, three = 1, 2, 3
print(f"one<two<three : {one < two < three}")
# one<two<three : True

중괄호 안에서 연쇄 비교가 계산되고, 그 bool 결과가 글자로 들어간다.

A chained comparison is evaluated inside the braces, and that bool becomes text.

#

표기notation

특징Behavior

주석 기호 #부터 그 줄 끝까지는 실행되지 않는다. 인터프리터가 그 구간을 코드로 읽지 않는다. 프로그램의 결과값에는 영향을 주지 않는다.

From the comment marker # to the end of that line, nothing is executed. The interpreter does not read that span as code. Comments do not change the program’s results.

사용Usage

# 여기부터 줄 끝은 무시

줄 맨 앞에 두어 한 줄 전체를 끄거나, 코드 뒤에 두어 짧은 설명을 남긴다. 잠시 실행하고 싶지 않은 줄을 지우는 대신 #로 막아 두는 때도 많다.

Place it at the start of a line to disable the whole line, or after code to leave a short note. A common habit is to keep a line out of execution with # instead of deleting it.

보충Notes

큰따옴표 세 개 """..."""는 주석 문법이 아니라 여러 줄 문자열이다. 이름에 대입하지 않으면 그 값은 만들어졌다가 버려진다. 실습 파일에서 코드 덩어리를 이렇게 감싸 둔 경우가 있다.

Triple quotes """...""" are not comment syntax; they build a multiline string. If it is not assigned, the value is created and then discarded. Lab files sometimes wrap a block of code that way.

예시Example

print(1)
# print(2)
print(3)
# 1
# 3

가운데 줄은 # 때문에 호출되지 않는다. 1과 3만 출력된다.

The middle line is not called because of #. Only 1 and 3 are printed.

n = 4  # temporary value
print(n)
# 4

코드와 같은 줄의 # 뒤는 설명이다. n = 4는 그대로 실행된다.

Text after # on the same line is a remark. n = 4 still runs.

변수와 자료형Names and types

이름은 값을 가리킨다. = 은 같다는 비교가 아니라 대입(assignment)이다.A name refers to a value. = is assignment, not a comparison of equality.

=

연산자operator

특징Behavior

대입 =은 “같다”는 비교가 아니다. 오른쪽 식을 먼저 계산하고, 그 결과 값을 왼쪽 이름에 연결한다. 같은지 비교할 때는 ==를 쓴다.

Assignment = is not a comparison of equality. The right-hand expression is evaluated first, then that result is bound to the name on the left. Equality uses ==.

사용Usage

이름 = 식

왼쪽은 값이 아니라 이름이어야 한다. 이미 쓰이던 이름에 다시 대입하면, 예전에 가리키던 값과의 연결은 끊기고 새 값을 가리킨다. n = n - 2는 오른쪽에 적힌 현재 n으로 계산한 뒤, 그 결과를 다시 n에 넣는다.

The left side must be a name, not a bare value. Assigning again to a name drops the old binding and refers to the new value. n = n - 2 evaluates the right side from the current n, then stores the result back in n.

보충Notes

대입문 자체는 화면에 아무것도 쓰지 않는다. 값을 확인하려면 print를 따로 호출한다. 수업에서 변수를 두는 이유는 같은 값을 이름으로 다시 쓰기 위함이다.

An assignment writes nothing to the screen by itself. Call print to inspect a value. Names exist so the same value can be reused by that name.

예시Example

n = 9
print(n)
# 9

이름 n이 정수 9를 가리킨다.

The name n refers to the integer 9.

n = 9
n = n - 2
print(n)
# 7

오른쪽의 n은 아직 9다. 9 - 2인 7이 계산된 뒤 n에 다시 연결된다.

The n on the right is still 9. 9 - 2 yields 7, which is then bound to n again.

a = b = 값

표기notation

특징Behavior

연쇄 대입은 오른쪽 식을 한 번만 계산하고, 그 같은 결과를 왼쪽에 나열된 이름에 차례로 연결한다. a = b = 2이면 a와 b가 모두 2를 가리킨다.

Chained assignment evaluates the right-hand expression once and binds that same result to each name listed on the left. With a = b = 2, both a and b refer to 2.

사용Usage

a = b = 식

초기값을 여러 이름에 같이 줄 때 쓴다. 나중에 a = 3만 다시 대입하면 a만 바뀌고 b는 이전 값을 유지한다(불변 정수·문자열의 경우).

Use it to give several names the same initial value. A later a = 3 rebinds only a; b keeps the previous value when that value is an immutable int or string.

보충Notes

리스트처럼 가변 객체를 연쇄 대입하면 두 이름이 같은 리스트를 공유한다. 한쪽에서 append하면 다른 이름에서도 보인다. 정수를 나누어 담는 실습 예제와는 상황이 다르다.

Chained assignment of a mutable object such as a list makes both names share that list. An append through one name is visible through the other. That differs from the lab case of sharing an integer.

예시Example

a = b = 2
print(a, b)
# 2 2

식 2가 한 번 계산되고 a와 b에 연결된다.

The expression 2 is evaluated once and bound to both a and b.

a = b = 2
a = 5
print(a, b)
# 5 2

a만 5로 다시 연결된다. b는 여전히 2다.

Only a is rebound to 5. b is still 2.

언패킹

표기notation

특징Behavior

언패킹은 오른쪽 묶음의 칸을 왼쪽 이름에 앞에서부터 하나씩 나눠 담는 대입이다. 리스트·튜플·문자열처럼 순서가 있는 값에 쓴다. 0번 칸이 첫 이름, 1번 칸이 둘째 이름으로 간다.

Unpacking is an assignment that places each cell of a sequence into the names on the left, from front to back. It applies to ordered values such as lists, tuples, and strings. Cell 0 goes to the first name, cell 1 to the second.

사용Usage

a, b = 묶음

왼쪽 이름의 개수와 오른쪽 칸의 개수가 같아야 한다. 다르면 ValueError다. 오른쪽을 쉼표로만 나열하면 튜플로 묶인 뒤 풀린다. 남는 칸을 한 이름에 리스트로 모을 때는 나중 단원의 * 패킹을 쓴다.

The number of names on the left must equal the number of cells on the right. A mismatch raises ValueError. A comma-separated right side is packed into a tuple and then unpacked. Gathering leftover cells into one name uses * packing in a later chapter.

보충Notes

칸의 값 자료형은 그대로다. ["Ada", "20"]을 풀면 age에도 글자 "20"이 들어가며, 정수 20이 아니다. 수 연산이 필요하면 int로 변환한다.

Each cell keeps its type. Unpacking ["Ada", "20"] puts the text "20" in age, not the integer 20. Convert with int before arithmetic.

예시Example

name, age = ["Ada", "20"]
print(name)  # Ada
print(age)   # 20
print(type(age))  # <class 'str'>

0번 Ada → name, 1번 "20" → age. age는 문자열이다.

Cell 0 Ada → name, cell 1 "20" → age. age is a string.

a, b = 1, 2
print(a, b)
# 1 2

오른쪽 1, 2가 튜플로 묶인 뒤 a와 b에 풀린다.

The right-hand 1, 2 is packed into a tuple, then unpacked into a and b.

# a, b = [1]
# ValueError: not enough values to unpack

이름 두 개인데 칸이 하나면 오류다.

Two names and one cell raise an error.

int float str bool

자료형type

특징Behavior

자료형(type)은 그 값으로 어떤 연산을 할 수 있는지를 정한다. 이 수업의 기본 형은 정수 int, 실수 float, 문자열 str, 논리값 bool이다. bool 값은 True와 False뿐이다. type(값)은 그 값의 형을 반환한다.

A type decides which operations a value may take part in. The basic types in this course are int, float, str, and bool. The only bool values are True and False. type(value) returns that value’s type.

사용Usage

type(값)

출력하면 <class 'int'>처럼 보인다. 형을 바꿀 때는 다음 단원의 int, float, str 같은 변환 함수를 호출한다. type 호출만으로는 원래 값이 바뀌지 않는다.

Printed, it looks like <class 'int'>. To change type, call a conversion such as int, float, or str in the next chapter. Calling type alone does not change the original value.

보충Notes

같은 글자라도 자료형이 다르면 쓰임이 다르다. 정수 4와 문자열 "4"는 print 결과는 비슷해 보여도, 하나는 더하기가 되고 하나는 글자 연결이 된다.

The same characters can mean different things under different types. The integer 4 and the string "4" may look alike when printed, but one takes part in addition and the other in text joining.

예시Example

number = 9
print(type(number))
# <class 'int'>

9는 int다.

9 is an int.

print(type(9.0))   # <class 'float'>
print(type("9"))   # <class 'str'>
print(type(True))  # <class 'bool'>

점·따옴표·True 표기에 따라 형이 갈린다.

A dot, quotes, or the True literal selects the type.

이름 규칙

규칙rule

특징Behavior

이름은 값을 가리키는 별칭이다. 수업 규칙으로는 예약어(if, for, while 등)를 이름으로 쓰지 않고, 특수문자는 밑줄 _만 허용하며, 숫자로 시작할 수 없다. 대문자와 소문자는 다른 이름이다.

A name is an alias for a value. Course rules: reserved words (if, for, while, …) cannot be names; the only special character allowed is underscore _; a name cannot start with a digit. Upper and lower case are different names.

사용Usage

score_1

여러 단어를 이을 때 공백 대신 밑줄을 쓴다. n과 N은 별개다. 1score처럼 숫자로 시작하면 SyntaxError다.

Join words with underscores instead of spaces. n and N are distinct. Starting with a digit, as in 1score, is a SyntaxError.

보충Notes

의미 있는 이름을 쓰면 대입과 조건을 읽기 쉽다. 한 글자 이름은 짧은 반복 변수에 자주 쓰고, 점수·이름처럼 오래 남는 값에는 풀이름을 쓰는 편이 좋다.

Meaningful names make assignments and conditions easier to read. Single-letter names are common for short loop variables; longer-lived values such as scores or names are clearer with full words.

예시Example

score_1 = 10
print(score_1)
# 10

밑줄과 숫자는 이름 중간에 올 수 있다.

Underscores and digits may appear in the middle of a name.

# 1score = 10   # SyntaxError: invalid decimal literal
# for = 3       # SyntaxError: invalid syntax

int()

함수function

특징Behavior

연산자(operator)는 피연산자를 받아 새 값을 만든다. 복합 대입만 왼쪽 이름을 다시 연결한다.An operator takes operands and produces a new value. Only an augmented assignment rebinds the name on the left.

산술

연산자operator

특징Behavior

산술 연산자는 계산 결과를 새로 반환한다. 피연산자가 실수이면 결과도 실수다. /는 양쪽이 정수여도 항상 float를 반환한다. //는 몫, %는 나머지, **는 거듭제곱이다.

An arithmetic operator returns a new result. If an operand is a float, the result is a float. / always returns a float, even for two integers. // is the floor quotient, % is the remainder, and ** is exponentiation.

사용Usage

실습의 9.0으로 보면 9.0 / 2는 4.5, 9.0 % 2는 1.0, 9.0 * 2는 18.0, 9.0 // 2는 4.0, 9.0 ** 3은 729.0이다. **의 지수가 0.5이면 제곱근이다.

보충Notes

문자열과 리스트와 튜플에서 +는 이어 붙인 새 값을, *는 정수 횟수만큼 반복한 새 값을 만든다. 이 경우에도 원본은 유지된다.

For a string, a list, or a tuple, + builds a new joined value and * builds a new value repeated an integer number of times. The originals stay as they were.

예시Example

init_number // 2    # 4.0
init_number % 2     # 1.0

연산자operator

특징Behavior

복합 대입은 “지금 이름에 들어 있는 값”과 오른쪽 식을 계산한 뒤, 그 결과를 같은 이름에 다시 넣는 표기다. n *= 2는 n = n * 2와 같은 뜻이다.

Augmented assignment means: take the value currently bound to the name, compute with the right-hand expression, then store that result back in the same name. n *= 2 means the same as n = n * 2.

사용Usage

이름 += 값 이름 -= 값 이름 *= 값 이름 /= 값 이름 //= 값 이름 %= 값

오른쪽 식이 먼저 계산된다. 강의 표기 variable ☆= expression은 variable = variable ☆ expression이다. 그래서 t *= 2 + 3은 t = t * (2 + 3)이고, t가 4였다면 20이 된다. 왼쪽은 이미 값이 있는 이름이어야 한다.

The expression on the right is evaluated first. The lecture form variable ☆= expression means variable = variable ☆ expression. So t *= 2 + 3 is t = t * (2 + 3); if t was 4, it becomes 20. The left side must already hold a value.

보충Notes

리스트에서 lst += 묶음은 extend와 비슷하게 같은 리스트에 칸을 이어 붙인다. 그 쓰임은 리스트 단원에서 다시 본다.

On a list, lst += sequence extends that same list, similar to extend. That use returns in the list chapter.

예시Example

4 * 2 yields 8, which is stored back in n.

먼저 2 + 3이 5가 되고, t = t * 5로 20이 된다.

First 2 + 3 becomes 5, then t = t * 5 makes 20.

조건Conditions

조건이 참인 갈래만 실행한다. 본문은 들여쓰기로 묶인다.Only the branch whose condition is true runs. Indentation groups the body.

if

문statement

특징Behavior

if는 조건을 검사한 뒤, 그 조건이 참(true)일 때만 들여쓴 본문을 실행하는 문이다. 조건이 거짓이면 본문 전체를 건너뛰고 다음 문장으로 간다. 조건에는 비교·멤버십·bool 값이 온다.

if tests a condition and runs its indented body only when that condition is true. A false condition skips the whole body and continues with the next statement. The condition is usually a comparison, a membership test, or a bool.

사용Usage

if 조건:

조건 뒤에 콜론(:)을 둔다. 본문은 같은 너비로 들여쓴다. 강의는 스페이스 4칸을 권한다. 탭과 스페이스를 섞지 않는다. 본문이 여러 줄이면 모두 같은 들여쓰기다.

Put a colon (:) after the condition. Indent the body by a consistent width. The lecture recommends four spaces. Do not mix tabs and spaces. Every line of a multi-line body shares that indent.

보충Notes

조건식 자체가 True/False를 만든다. if n < 5:에서 n이 3이면 비교 결과는 True라 본문이 실행된다. 본문에서 이름을 바꿔도, 이미 지나간 if의 조건을 다시 검사하지는 않는다.

The condition expression itself produces True or False. In if n < 5:, when n is 3 the comparison is True and the body runs. Changing a name inside the body does not re-test that if’s condition.

예시Example

n = 3
if n < 5:
    print("n is less than 5")
# n is less than 5

조건이 거짓이라 if 본문은 건너뛰고, 들여쓰지 않은 print만 실행된다.

The condition is false, so the if body is skipped and only the unindented print runs.

elif else

문statement

특징Behavior

elif는 바로 위 조건이 거짓이었을 때만 다음 조건을 검사한다. else는 위쪽 if/elif가 모두 거짓일 때 실행되는 마지막 갈래다. 위에서 참인 갈래가 하나 실행되면, 그 아래 elif·else는 보지 않는다.

elif tests its condition only when the condition above was false. else is the final branch when every earlier if/elif was false. Once one true branch has run, later elif and else are not tested.

사용Usage

if 조건: ... elif 조건: ... else: ...

elif는 생략할 수 있고, 여러 개를 이을 수 있다. else도 생략할 수 있다. 각 헤더는 콜론으로 끝나고, 본문은 들여쓴다. 서로 겹치지 않는 구간(음수 / 0 / 한 자리 / 그 외)을 나눌 때 쓴다.

elif may be omitted, or several may be chained. else may also be omitted. Each header ends with a colon and its body is indented. Use this to split non-overlapping ranges (negative / zero / single digit / other).

보충Notes

위 조건이 참이면 아래를 평가하지 않으므로, 비싼 계산이나 오류가 날 수 있는 식은 아래 갈래에 두어도 위가 참이면 실행되지 않는다. 수업 예제 number=5는 세 번째 갈래 number < 10에서 single을 출력한다.

When an earlier condition is true, later ones are not evaluated, so a costly or error-prone expression in a lower branch stays unused. In the lecture example with number=5, the third branch number < 10 prints single.

예시Example

5 is neither negative nor zero, and it is less than 10, so only the single branch runs. else is not taken.

중첩 if

문statement

특징Behavior

중첩 if는 바깥 if의 본문 안에 또 if를 두는 구조다. 바깥 조건이 참일 때만 안쪽 조건을 검사한다. 바깥이 거짓이면 안쪽은 아예 보지 않는다.

A nested if places another if inside an outer if’s body. The inner condition is tested only when the outer condition is true. When the outer condition is false, the inner if is not looked at.

사용Usage

if 바깥조건: if 안쪽조건: ... else: ...

안쪽 블록은 바깥 본문보다 한 단계 더 들여쓴다(강의: 스페이스 4칸씩). 바깥에서 큰 범위를 고르고, 안쪽에서 짝수/홀수처럼 세부 갈래를 나눌 때 쓴다.

The inner block is indented one level deeper than the outer body (lecture: four spaces each level). Use an outer test for a broad range, then an inner test for a detail such as even versus odd.

보충Notes

안쪽 else는 안쪽 if에만 붙는다. 바깥 if의 else와 혼동하지 않도록 들여쓰기를 맞춘다. break는 반복 문에서 쓰는 말이고, if 갈래를 끝내는 전용 키워드는 아니다.

An inner else belongs only to the inner if. Keep indentation aligned so it is not read as the outer if’s else. break is for loops; it is not a special keyword for ending an if branch.

        print("even")
    else:
        print("odd")
# odd

바깥 5 < 10이 참이라 안쪽으로 들어간다. 5 % 2 == 0은 거짓이라 odd가 출력된다.

Outer 5 < 10 is true, so control enters the inner if. 5 % 2 == 0 is false, so odd is printed.

반복Loops

반복문(loop)은 조건이나 묶음의 칸이 남아 있는 동안 본문을 다시 실행한다. Programming-6에서는 끝없이 도는 경우와, break·continue로 흐름을 끊거나 건너뛰는 방법을 본다.A loop runs its body again while a condition holds, or while elements of a sequence remain. Programming-6 covers loops that keep going, and how break and continue end or skip a pass.

while

문statement

특징Behavior

while은 조건식(condition)을 먼저 보고, 그 값이 참(true)인 동안에만 들여쓴 본문을 다시 실행하는 문이다. 한 바퀴가 끝날 때마다 조건을 다시 검사한다. 조건이 거짓(false)이 되면 본문을 더 이상 실행하지 않고 다음 문장으로 넘어간다.

while checks a condition first, then runs its indented body again only while that condition is true. After each pass it tests the condition again. When the condition becomes false, the body stops and the next statement after the loop runs.

사용Usage

while 조건:

조건 뒤에는 콜론(:)을 두고, 본문은 네 칸 들여쓴다. 횟수가 미리 정해지지 않았을 때 쓴다. 예를 들어 입력이 아직 짧으면 다시 받거나, 어떤 값이 목표에 이를 때까지 계산을 이어 갈 때다. 본문 안에서 조건을 바꾸는 일이 있어야 반복이 끝난다. 조건을 바꾸는 일을 빼먹으면 끝없이 돈다.

Put a colon after the condition and indent the body by four spaces. Use it when the number of passes is not known in advance, for example when input must be read again while it is still too short, or while a value has not yet reached a goal. The body must change something that the condition looks at, or the loop keeps going.

보충Notes

조건을 직접 고치는 흔한 방법은 두 가지다. 하나는 숫자나 길이를 줄이거나 늘리는 것이다. 다른 하나는 불리언 이름(flag)을 두고, 본문에서 그 이름을 False로 바꾸는 것이다. 수업 예제의 status가 그 이름이다. while status:는 status가 참인 동안만 돌고, 본문에서 status = False가 되면 다음 검사에서 멈춘다.

Two common ways to change the condition are to grow or shrink a number or a length, and to keep a Boolean flag that the body sets to False. In the lecture game example that flag is status. while status: keeps running while status is true, and after status = False the next test ends the loop.

예시Example

stamina = 10
status = True
while status:
    print("Hello Python!")
    stamina -= 1
    if stamina == 0:
        status = False
print("Loop ended because stamina is 0.")
# Hello Python! 가 10번 출력된 뒤
# Loop ended because stamina is 0.

처음 status는 참이라 본문에 들어간다. 매 바퀴마다 체력(stamina)이 1씩 줄어든다. 체력이 0이 되면 status를 거짓으로 바꾼다. 그다음 조건을 다시 볼 때 반복이 끝나고, 아래 print가 한 번 실행된다.

At first status is true, so the body runs. Each pass lowers stamina by 1. When stamina reaches 0, status becomes false. The next condition check ends the loop, and the final print runs once.

while True

문statement

특징Behavior

무한 루프(infinite loop)는 끝없이 도는 반복이다. while True:처럼 조건이 항상 참이면, 본문 안에서 빠져나가는 일이 생기기 전까지 같은 본문이 계속 실행된다. 조건을 아예 없애거나, 조건을 거짓으로 만들 수 없게 둔 경우에도 같은 상황이 된다.

An infinite loop is a loop that does not end by itself. With while True:, the condition is always true, so the body keeps running until something inside the body ends the loop. The same thing happens when the exit condition can never become false.

사용Usage

while True:

의도적으로 쓸 때는 본문 안에서 끝나는 조건을 직접 둔다. 입력이 특정 글자와 같으면 끝내거나, 체력이 0이 되면 끝내는 식이다. 끝나는 조건을 빼먹으면 터미널에서 Ctrl + C로 프로그램을 끊을 수 있다. 이 키는 실행을 가로채서 반복을 멈춘다.

When you use it on purpose, put the exit test inside the body, for example when input matches a quit word, or when a resource reaches 0. If that exit is missing, press Ctrl + C in the terminal. That interrupt stops the program.

보충Notes

수업에서는 서버가 요청을 기다리는 일, 게임이 화면을 갱신하는 일, 센서가 값을 읽는 일, 사용자가 끝낼 때까지 명령을 받는 일처럼 일부러 오래 도는 경우를 든다. 이런 프로그램도 안쪽에서 끝나는 신호를 받으면 멈춘다. 실수로 만든 무한 루프와, 끝나는 지점이 본문에 있는 의도된 while True를 구분해서 보면 된다.

The lecture names intentional long-running cases: a server waiting for clients, a game updating the screen, a sensor reading values, and a program that takes commands until the user quits. Those programs still stop when an exit signal appears inside the body. Read accidental infinite loops and intentional while True loops that carry their own exit point as two different situations.

예시Example

stamina = 10
while True:
    print("You are exercising. Stamina decreases by 1.")
    stamina -= 1
    if not stamina:
        print("Your stamina is exhausted. Loop ended.")
        break

True는 항상 참이라 조건만으로는 끝나지 않는다. 매 바퀴마다 체력이 1 줄고, 체력이 0이 되면 if not stamina가 참이 된다. 그때 안내 문장을 출력한 뒤 break로 반복을 끝낸다. Hello Python만 계속 출력하는 코드에는 이런 탈출이 없어서 터미널에서 직접 끊어야 한다.

True is always true, so the condition alone never ends the loop. Each pass lowers stamina by 1, and when it reaches 0, if not stamina becomes true. The message prints, then break ends the loop. A loop that only prints Hello Python forever has no such exit, so it must be stopped in the terminal.

for

문statement

특징Behavior

for는 묶음(sequence)의 칸을 앞에서부터 하나씩 꺼내 이름에 연결한 뒤, 들여쓴 본문을 실행하는 문이다. 한 칸의 본문이 끝나면 다음 칸으로 간다. 칸이 더 없으면 반복이 끝나고 다음 문장으로 넘어간다. 보통 묶음 자체를 고치지 않고, 각 칸을 읽어 합이나 출력 같은 새 결과를 만든다.

for takes each element of a sequence from front to back, binds it to a name, and runs the indented body. When one pass finishes it moves to the next element. When no elements remain, the loop ends and the next statement runs. It usually leaves the sequence unchanged and builds a new result such as a sum or printed lines.

사용Usage

for 이름 in 묶음:

문자열이면 글자 하나, 리스트면 칸의 값이 이름에 들어간다. 횟수가 정해진 반복은 range와 함께 쓴다. 본문 안에서 break로 중간에 끝내거나, continue로 이번 칸의 나머지 일을 건너뛸 수 있다. Programming-6의 합산 예제가 그 패턴이다.

Over a string the name receives one character; over a list it receives one element. A counted repetition is written with range. Inside the body, break can end the loop early and continue can skip the rest of the current pass. The Programming-6 summing example uses that pattern.

보충Notes

while은 조건을 직접 쓰고, for는 묶음의 칸 개수만큼 돈다. 리스트를 돌다가 음수에서 멈추려면 for 본문에 if i < 0: break를 둔다. 짝수를 합에서 빼려면 continue를 둔다. 같은 이름 i가 매 칸마다 새 값으로 바뀐다.

while states a condition directly; for runs once per element of a sequence. To stop when a negative value appears in a list, put if i < 0: break in the body. To leave even values out of a sum, put continue. The same name i is rebound to each new cell.

예시Example

for ch in "Hi":
    print(ch)
# H
# i

data = [1, 4, 7]
total = 0
for i in data:
    if i % 2 == 0:
        continue
    total += i
print(total)
# 8

첫 예는 글자마다 한 줄씩 출력한다. 둘째 예는 1과 7만 더해 8이 되고, 짝수 4는 continue로 합에서 빠진다.

The first example prints one line per character. The second adds only 1 and 7, so the sum is 8, and the even value 4 is left out by continue.

range

함수function

특징Behavior

range는 정수만으로 된 수열을 만드는 함수다. for에 넘기면 그 수들이 이름에 하나씩 들어간다. 핵심은 끝 값(stop)이 수열에 들어가지 않는다는 점이다. range(1, 4)는 1, 2, 3이고 4는 없다. 시작(start)과 간격(step)을 함께 정할 수 있다.

range builds a sequence of integers. Passed to for, those integers bind to the loop name one by one. The stop value is never included: range(1, 4) is 1, 2, 3 and not 4. A start and a step can be set together with the stop.

사용Usage

range(stop) range(start, stop) range(start, stop, step)

인자가 하나면 0부터 stop 직전까지다. 둘이으면 start부터 stop 직전까지다. 셋이면 그 사이를 step만큼 건너뛴다. 1부터 n까지 모두 필요하면 끝을 n + 1로 둔다. step이 음수면 큰 수에서 작은 수로 내려간다. 이 경우에도 끝 값은 포함되지 않는다.

One argument means 0 up to, but not including, stop. Two arguments mean start up to, but not including, stop. Three arguments jump by step. To include every integer from 1 through n, set the stop to n + 1. A negative step counts downward, and the stop is still excluded.

보충Notes

range 자체는 리스트가 아니다. for가 필요할 때마다 다음 정수를 꺼낸다. 리스트로 보고 싶으면 list(range(...))를 쓴다. 끝 값이 빠지는 규칙은 슬라이스 s[start:stop]과 같은 계열이다.

range itself is not a list. for pulls the next integer when it needs one. Use list(range(...)) when a real list is required. Excluding the stop matches the rule of a slice s[start:stop].

예시Example

for i in range(1, 4):
    print(i)
# 1
# 2
# 3

시작 1은 들어가고 끝 4는 빠진다.

Start 1 is included and stop 4 is left out.

for i in range(0, 5, 2):
    print(i)
# 0
# 2
# 4

0부터 시작해 2씩 건너뛴다. 5는 끝이라 수열에 없다.

It starts at 0 and jumps by 2. 5 is the stop, so it is not in the sequence.

for i in range(3, 0, -1):
    print(i)
# 3
# 2
# 1

간격이 -1이라 3, 2, 1 순이다. 끝 0은 포함되지 않는다.

With step -1 the order is 3, 2, 1. The stop 0 is not included.

중첩 for

문statement

특징Behavior

중첩 for는 바깥 반복이 한 칸 진행할 때마다 안쪽 반복이 자기 묶음을 처음부터 끝까지 다시 도는 구조다. 바깥 값이 고정된 상태에서 안쪽 값이 모두 바뀌고, 안쪽이 끝나면 바깥이 다음 칸으로 간다.

A nested for runs the whole inner sequence again for each step of the outer loop. While the outer value stays fixed, the inner value walks its full sequence; when the inner loop finishes, the outer loop moves to its next element.

사용Usage

for a in 묶음: for b in 묶음:

서로 다른 두 번호가 필요할 때 쓴다. 구구단, 표의 행·열, 좌표 쌍이 그 예다. 안쪽 for는 바깥 본문보다 한 단계 더 들여쓴다. 안쪽에 둔 break는 안쪽 반복만 끝내고, 바깥 반복은 다음 칸으로 이어진다.

Use it when two independent numbers are required, as in a multiplication table, a grid of rows and columns, or coordinate pairs. The inner for is indented one level deeper than the outer body. A break inside the inner loop ends only that inner loop; the outer loop continues with its next element.

보충Notes

바깥이 n번, 안쪽이 m번이면 안쪽 본문은 대략 n×m번 실행된다. 디버깅할 때는 바깥 값이 바뀔 때마다 안쪽이 다시 0번 칸부터 시작하는지 보면 된다.

If the outer loop runs n times and the inner loop m times, the inner body runs about n×m times. When debugging, check that the inner loop restarts from its first element every time the outer value changes.

예시Example

for i in range(2, 4):
    for j in range(1, 3):
        print(i, j)
# 2 1
# 2 2
# 3 1
# 3 2

바깥 i가 2일 때 안쪽 j는 1, 2를 모두 돈다. 그다음 i가 3이 되면 안쪽은 다시 1, 2부터 시작한다.

While outer i is 2, inner j walks 1 then 2. When i becomes 3, the inner loop starts again at 1 and 2.

for i in range(2, 4):
    for j in range(1, 4):
        if j == 2:
            break
        print(i, j)
# 2 1
# 3 1

안쪽 break는 j == 2에서 안쪽만 끝낸다. 바깥 i는 3으로 이어지므로 출력은 두 줄이다.

The inner break ends only the inner loop when j == 2. Outer i still continues to 3, so two lines are printed.

while else

문statement

특징Behavior

while 뒤에 붙는 else는 반복이 조건이 거짓이 되어 평범하게 끝났을 때만 실행된다. 본문에서 break로 빠져나가면 else는 실행되지 않는다. return으로 함수를 나가거나, 본문에서 예외가 나도 실행되지 않는다. continue는 반복을 끝내지 않으므로 else 실행 여부와는 별개다.

The else after while runs only when the loop ends normally because the condition became false. It does not run after a break, after a return, or after an exception in the body. continue does not end the loop, so it is separate from whether else later runs.

사용Usage

while 조건: 본문 else: 평범하게 끝났을 때

while과 else 모두 콜론으로 끝난다. else는 생략할 수 있다. “끝까지 돌았는지”를 표시하고 싶을 때 쓴다. 중간에 목표를 찾으면 break하고, 못 찾고 조건이 거짓이 되면 else에서 안내를 출력하는 식이다.

Both while and else end with a colon. The else may be omitted. Use it when the program should mark that the loop ran to completion. A common pattern is to break when a target is found, and to print a note in else when the condition became false without a find.

보충Notes

for에도 같은 형태의 else가 있다. 칸을 모두 돌고 평범하게 끝나면 실행되고, break로 끝나면 실행되지 않는다. 수업의 홀수 합 예제에서 for 뒤 else: print(total)이 그 쓰임이다.

for has the same kind of else. It runs after every element is visited normally, and it stays silent after a break. In the lecture odd-sum example, else: print(total) after for is that use.

예시Example

k = 0
while k < 2:
    k = k + 1
else:
    print(k)
# 2

조건이 거짓이 되어 끝났으므로 else가 실행되고 2가 출력된다.

The loop ended because the condition became false, so else runs and prints 2.

k = 0
while k < 5:
    k = k + 1
    if k == 2:
        break
else:
    print("normal end")
print("after", k)
# after 2

break로 끝났으므로 else의 문장은 실행되지 않는다. 반복 밖의 print만 실행된다.

Because the loop ended with break, the else body does not run. Only the print after the loop runs.

break

문statement

특징Behavior

break는 “여기서 이 반복을 끝내고 싶다”고 말할 때 쓴다. 실행되는 순간, 그 뒤에 남아 있는 본문 줄은 모두 건너뛰고, 그 break가 들어 있는 반복 자체를 즉시 종료한다. 프로그램 전체가 끝나는 것은 아니고, 그 반복 바로 다음에 있는 문장으로 이어진다.

break means “end this loop here.” When it runs, the rest of the body after it is skipped, and the loop that contains that break ends at once. The whole program does not exit; control continues with the statement after that loop.

사용Usage

break

반복 본문 안에서만 쓴다. while True처럼 조건만으로는 끝나지 않는 반복에서, 입력이나 계산 결과가 끝 조건에 맞을 때 둔다. 중첩 반복이면 break는 가장 안쪽 반복만 빠져나온다. 바깥 반복은 그대로 이어진다. while 뒤의 else는 break로 끝난 경우에는 실행되지 않는다.

Write it only inside a loop body. In a loop such as while True, place it when input or a computed value matches the exit condition. In nested loops, break leaves only the innermost loop that contains it; the outer loop continues. A while else does not run when the loop ended by break.

보충Notes

수업 예제에서는 사용자가 -1을 입력하면 프로그램을 끝내고, 리스트를 돌다가 음수를 만나면 합산을 멈춘다. break 앞의 print는 실행되고, break 뒤에 있던 같은 바퀴의 줄은 실행되지 않는다. 몇 번 돌지 미리 모를 때도, “이 값이 나오면 그만”이라는 지점을 break로 표시한다.

In the lecture examples, the program quits when the user enters -1, and a list walk stops accumulating when a negative number appears. A print before break still runs; lines after break in the same pass do not. When the number of passes is unknown, break marks the point “stop when this value appears.”

예시Example

while True:
    answer = input("Enter anything (enter -1 to quit): ")
    if answer == "-1":
        print("Program terminated...")
        break
    print(answer)

입력이 -1이면 종료 안내를 출력한 뒤 break로 반복을 끝낸다. 그 경우 아래 print(answer)는 실행되지 않는다. 다른 글자를 치면 그 글자를 출력하고 다시 입력을 받는다.

When the input is -1, the quit message prints and break ends the loop, so print(answer) below does not run for that pass. Any other text is printed, and the loop asks again.

continue

문statement

특징Behavior

continue는 “이번 바퀴의 나머지 일은 건너뛰고, 다음 바퀴로 가고 싶다”고 말할 때 쓴다. 실행되는 순간 그 뒤에 남아 있는 본문 줄은 모두 건너뛴다. 반복 자체는 끝나지 않는다. for면 다음 칸으로, while이면 조건을 다시 보는 곳으로 돌아간다.

continue means “skip the rest of this pass and go to the next one.” When it runs, the remaining lines of the body are skipped. The loop itself does not end. A for moves to the next element, and a while returns to the condition test.

사용Usage

continue

반복 본문 안에서만 쓴다. 어떤 값은 처리하고, 어떤 값은 합에 넣지 않을 때 앞에 둔다. 수업 예제에서는 짝수면 continue로 합산에서 빼고, 홀수만 total에 더한다. break와 같이 쓰면 보통 끝낼 조건을 먼저 보고, 건너뛸 조건을 다음에 본다.

Write it only inside a loop body. Place it before work that should run for some values and be skipped for others. In the lecture example, even numbers hit continue and leave the sum unchanged, while odd numbers are added to total. Together with break, the exit test usually comes first, then the skip test.

보충Notes

break는 반복을 끝내고, continue는 이번만 건너뛴다. 1부터 100까지 홀수만 더하는 예에서는 짝수일 때 continue가 나와 total += i가 실행되지 않는다. 합은 2500이다. 리스트 예에서는 음수에서 break, 짝수에서 continue, 그 밖의 홀수만 더한다. -1 앞까지 모은 홀수 합은 32이고, 뒤의 22와 31은 보지 않는다.

break ends the loop; continue skips only the current pass. In the sum of odd numbers from 1 through 100, even values hit continue so total += i does not run, and the sum is 2500. In the list example, a negative value hits break, an even value hits continue, and only the other odd values are added. The odd sum before -1 is 32; 22 and 31 after it are never seen.

예시Example

total = 0
for i in range(1, 11):
    if i % 2 == 0:
        continue
    total += i
print(total)
# 25

1부터 10까지 본다. 짝수면 continue로 합산을 건너뛰고, 홀수 1·3·5·7·9만 더해 25가 된다. 이 예에는 break가 없다.

The loop looks at 1 through 10. Even values hit continue and skip the sum; only the odds 1, 3, 5, 7, and 9 are added, so the total is 25. This example has no break.

data = [1, 4, 7, 3, 8, 6, 9, 5, 0, 2, 7, -1, 22, 31]
total = 0
for i in data:
    if i < 0:
        print(f"Negative number (i = {i}) -> break")
        break
    elif i % 2 == 0:
        print(f"Even number (i = {i}) -> continue")
        continue
    else:
        print(i)
        total += i
print("Sum of odd numbers:", total)
# Sum of odd numbers: 32

수업 예제다. 음수에서 break, 짝수에서 continue, 나머지 홀수만 더한다. -1 앞까지 모은 합은 32이고, 뒤의 22와 31은 읽지 않는다.

This is the lecture example. A negative value hits break, an even value hits continue, and only the other odd values are added. The sum before -1 is 32; 22 and 31 after it are unread.

enumerate

함수function

특징Behavior

enumerate는 묶음의 각 칸을 (번호, 값) 쌍으로 내놓는 함수다. 값만 도는 for x in 묶음과 달리, 몇 번째 칸인지도 함께 필요할 때 쓴다. 번호는 기본으로 0부터 시작한다.

enumerate yields each element of a sequence as an (index, value) pair. Unlike for x in sequence, which only binds the value, it is used when the position is needed as well. The index starts at 0 by default.

사용Usage

for i, x in enumerate(묶음): for i, x in enumerate(묶음, start=1):

왼쪽에서 쌍을 두 이름에 푼다. 첫 이름이 번호, 둘째가 값이다. start를 주면 첫 번호가 그 값으로 바뀐다. 사람 눈에 보이는 1번부터 세고 싶을 때 start=1을 둔다.

The left side unpacks each pair into two names: the first is the index and the second is the value. With start, the first index becomes that value. Use start=1 when the count should begin at 1 for display.

보충Notes

번호는 묶음을 고치지 않는다. 리스트의 칸을 번호로 바꾸려면 여전히 lst[i] = 값처럼 인덱스를 쓴다. enumerate가 내주는 번호와 리스트 인덱스는 기본값 0에서 같은 위치다.

The index does not modify the sequence. To change a list cell by position, still use lst[i] = value. With the default start of 0, the number from enumerate matches the list index of that cell.

예시Example

for i, ch in enumerate("Hi"):
    print(i, ch)
# 0 H
# 1 i

첫 글자 H의 번호는 0, 둘째 글자 i의 번호는 1이다.

The character H has index 0 and i has index 1.

for i, ch in enumerate("Hi", start=1):
    print(i, ch)
# 1 H
# 2 i

start=1이면 화면에 보이는 순번이 1, 2로 시작한다. 글자 자체는 같다.

With start=1 the displayed numbers begin at 1 and 2. The characters themselves stay the same.

for 딕셔너리 · zip

문statement

특징Behavior

딕셔너리를 for로 돌면 값이 아니라 키(key)가 이름에 들어간다. 값까지 함께 보려면 d.items()가 내주는 (키, 값) 쌍을 돈다. zip은 여러 묶음에서 같은 위치의 칸을 짝으로 묶는다. 짧은 쪽의 칸이 끝나면 zip도 멈춘다.

A for over a dictionary binds keys, not values. To see values as well, iterate the (key, value) pairs from d.items(). zip pairs cells that share a position across several sequences, and it stops when the shortest sequence ends.

사용Usage

for key in d: for key, value in d.items(): for a, b in zip(xs, ys):

키만 필요하면 for key in d로 충분하다. 메뉴 이름과 가격처럼 짝이 필요하면 items()를 쓴다. 두 리스트를 나란히 처리할 때는 zip을 쓴다. 길이가 다르면 남는 칸은 짝이 없어 버려진다.

for key in d is enough when only keys are needed. Use items() when pairs such as a menu name and a price are required. Use zip to walk two lists side by side. When the lengths differ, leftover cells without a partner are dropped.

보충Notes

key in d 멤버십 검사도 키만 본다. 값 안에 어떤 수가 있는지는 in으로 바로 확인하지 않는다. zip의 결과는 한 번 돌면 끝나는 이터레이터라서, 같은 짝을 다시 쓰려면 다시 zip(...)을 호출하거나 list(zip(...))로 저장한다.

Membership with key in d also checks keys only. It does not look inside the values. The result of zip is an iterator that is spent after one pass, so call zip(...) again or store list(zip(...)) when the pairs are needed twice.

예시Example

menu = {"Burger": 5500, "Pizza": 8500}
for key in menu:
    print(key)
# Burger
# Pizza

키만 순서대로 출력된다. 가격 숫자는 이 반복의 이름에 들어오지 않는다.

Only the keys are printed in order. The prices do not bind to the loop name in this form.

for key, price in menu.items():
    print(key, price)
# Burger 5500
# Pizza 8500

items()로 키와 값을 한 쌍씩 받는다.

items() yields each key with its value as a pair.

for a, b in zip([2, 3], [1]):
    print(a, b)
# 2 1

둘째 묶음 길이가 1이라 짝은 한 개뿐이다. 남는 3은 출력되지 않는다.

The second sequence has length 1, so there is only one pair. The leftover 3 is not printed.

인덱스와 슬라이스Index and slice

문자열, 리스트, 튜플은 0부터 번호를 센다. 슬라이스의 끝 번호는 빠진다.Strings, lists, and tuples count from 0. The stop of a slice is excluded.

인덱스

표기notation

특징Behavior

인덱스(index)는 칸의 번호다. 첫 칸은 0이고, 마지막 칸은 -1이다. 그 번호의 칸 하나를 꺼낸다.

An index is the position of an element. The first position is 0, and the last is -1. The notation retrieves that one element.

사용Usage

묶음[번호]

길이가 n이면 유효한 번호는 0부터 n-1까지, 또는 -1부터 -n까지다. 그 밖은 IndexError다. 가운데 칸은 len(묶음) // 2로 구한다.

If the length is n, valid indexes run from 0 through n-1, or from -1 through -n. Anything outside that raises IndexError. The middle element is at len(sequence) // 2.

보충Notes

문자열과 튜플은 이 자리에 대입할 수 없다. 리스트만 lst[i] = 값이 성립한다.

A string or a tuple cannot be assigned at this position. Only a list accepts lst[i] = value.

예시Example

s = "Python"
s[0]     # P
s[-1]    # n

슬라이스

표기notation

특징Behavior

슬라이스(slice)는 구간의 칸으로 새 문자열, 새 리스트, 또는 새 튜플을 만든다. 끝 번호의 칸은 포함하지 않는다. 원본은 유지된다.

A slice builds a new string, list, or tuple from a span of elements. The element at the stop index is not included. The original is left as it was.

사용Usage

묶음[시작:끝:간격]

시작을 비우면 처음부터, 끝을 비우면 마지막까지다. 간격만 음수로 두면 순서가 뒤집힌다. [::-1]이 그 형태다.

An empty start means the beginning, and an empty stop means through the end. A negative step reverses the order. [::-1] is that form.

예시Example

"Python"[1:-1]    # ytho
"Python"[::-1]    # nohtyP

len

함수function

특징Behavior

len은 칸의 개수를 정수로 반환하는 함수다. 마지막 인덱스는 그 값보다 1 작다.

len is a function that returns the number of elements as an integer. The last index is one less than that number.

사용Usage

len(묶음)

문자열은 문자의 수, 리스트와 튜플은 칸의 수, 딕셔너리는 키의 수다. 비어 있으면 0이다.

For a string it is the number of characters, for a list or tuple the number of elements, and for a dictionary the number of keys. An empty value has length 0.

예시Example

len("Python")    # 6

문자열Strings

문자열(string)은 순서가 있는 불변 값이다. 메서드는 원본을 두지 않고 새 문자열이나 리스트를 반환한다.A string is an ordered immutable value. Its methods leave the original in place and return a new string or a new list.

문자열

자료형type

특징Behavior

문자열의 한 칸은 대입으로 바꿀 수 없다. 바꾸려면 슬라이스와 +로 새 문자열을 만들고, 그 결과를 이름에 다시 대입한다.

One character of a string cannot be replaced by assignment. To change the text, build a new string with slices and +, then assign that result back to the name.

사용Usage

s[0] = "a" # 성립하지 않음

첫 문자와 마지막 문자를 바꾸는 실습은 s[-1] + s[1:-1] + s[0]이다. 가운데는 끝 문자를 뺀 구간이다.

The lab that swaps the first and last characters is s[-1] + s[1:-1] + s[0]. The middle is the slice that excludes both ends.

예시Example

s = "Python"
s = s[-1] + s[1:-1] + s[0]
# nythoP

split

메서드method

특징Behavior

split은 문자열을 잘라 리스트로 반환하는 메서드(method)다. 원래 문자열은 바뀌지 않는다.

split is a method that divides a string and returns a list. The original string does not change.

사용Usage

s.split(구분자)

인자를 비우면 연속된 공백을 구분자(separator)로 보고, 빈 칸은 결과에 넣지 않는다. 구분자를 주면 그 문자열을 경계로 자른다.

With no argument, consecutive whitespace is the separator and empty pieces are omitted. With a separator, the string is divided on that text.

예시Example

"a b".split()       # ['a', 'b']
"a,b".split(",")    # ['a', 'b']

join

메서드method

특징Behavior

join은 묶음의 각 조각을 구분자로 이어 새 문자열을 반환한다. 구분자가 메서드 앞에 오고, 이어 붙일 재료가 인자다.

join returns a new string made by placing the separator between the pieces. The separator stands before the method, and the pieces are the argument.

사용Usage

구분자.join(묶음)

인자의 칸은 모두 문자열이어야 한다. 수가 섞이면 TypeError다. 문자열을 넘기면 문자 하나씩이 조각이 된다.

Every element of the argument must be a string. A number among them raises TypeError. Passing a string treats each character as a piece.

예시Example

" ".join(["I", "love"])

얕은 복사

연산operation

특징Behavior

얕은 복사는 바깥 객체만 새로 만들고, 안의 객체는 원본과 같은 참조를 공유한다. 리스트와 딕셔너리의 copy가 이 복사다. 바깥에 칸을 더해도 원본의 바깥은 그대로이고, 안의 리스트를 고치면 원본의 그 리스트도 바뀐다.

A shallow copy builds a new outer object and shares the inner objects with the original. copy on a list or a dictionary is this copy. Adding a cell to the outer copy leaves the original's outer container, while editing an inner list changes that list in the original too.

예시Example

print(c)

A deep copy recursively copies the outer object and the mutable objects inside it, so the copy shares no references with the original. copy.deepcopy does that work.

사용Usage

import copy copy.deepcopy(객체)

사본 안의 리스트를 고쳐도 원본 안의 리스트는 유지된다.

Editing a list inside the copy leaves the list inside the original as it was.

예시Example

d = copy.deepcopy(a)
d[0][0] = 9
print(a)
print(d)
# [[1], 2]
# [[9], 2]
